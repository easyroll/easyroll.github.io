    SmartThings 연동

    Works With SmartThings 공식 인증 제품

    이지롤 스마트블라인드(EasyRoll Smartblind)는 삼성 SmartThings의 WWST(Works With SmartThings) 인증을 받은 정식 파트너 기기입니다. SmartThings 앱에서 별도 허브 없이 삼성 계정과 이지롤 계정만 있으면 바로 연결되고 빅스비·루틴(자동화) 까지 정식으로 지원됩니다.

    이지롤 스마트블라인드를 삼성 SmartThings에 연결하면, 갤럭시폰·삼성 가전과 한 화면에서 제어하고 빅스비 음성으로도 작동할 수 있습니다.

    인증으로 지원되는 기능

    기능 SmartThings에서
    열기 · 닫기 · 정지 기기 카드의 닫기 · 일시정지 · 열림 버튼 / 빅스비 / 루틴
    위치 % 조절 슬라이더로 원하는 높이 (100% = 완전 열림, 0% = 완전 닫힘 — SmartThings 기준)
    프리셋 위치 m1 · m2 · m3 카드의 ◎ 를 누르면 미리 정한 높이로 한 번에 이동, ⚙ 에서 높이 변경 (처음 설정값 25% / 50% / 75%)
    동작 상태 표시 열리는 중 / 닫히는 중 / 열림 / 닫힘 / 일부 열림 — 블라인드를 움직이면 카드가 자동으로 함께 갱신
    온라인 / 오프라인 표시 블라인드 전원·인터넷이 끊기면 SmartThings에 "오프라인"으로 표시

    💡 그림에서 m1·m2·m3 카드의 "기본 위치" 42 / 65 / 85는 ⚙에서 높이를 바꿔 둔 예시예요. 처음 연결하면 25 / 50 / 75로 시작합니다.

    💡 SmartThings의 프리셋 m1·m2·m3은 이지롤 앱의 M1~M3 저장 위치와는 별개입니다. 각각 따로 설정해 두고 쓰시면 됩니다.

    준비물

    • 이지롤 앱에 블라인드가 등록된 계정 (기기 등록하기 완료 상태)
    • 블라인드를 직접 등록한(소유자) 계정으로 연결하세요 — 구성원으로 공유받은 블라인드는 연동되지 않습니다.
    • 스마트폰에 SmartThings 앱 설치 + 삼성 계정 로그인
    • 블라인드가 인터넷(집 WiFi)에 연결된 상태 — SmartThings 연동은 이지롤 서버를 통해 동작합니다

    연결하기 (처음 한 번)

    1. SmartThings 앱 → [+ 기기 추가] → 제휴사 기기의 [추가]

    2. 브랜드 목록에서 EasyRoll SmartBlind 선택 (🔍 검색창에 "EasyRoll"을 입력하면 바로 찾을 수 있어요)

      ⚠️ 목록에 비슷한 이름의 EasyRoll(예전 연동)도 보입니다. 새로 연결할 때는 꼭 EasyRoll SmartBlind(인증 버전)를 선택하세요.

    3. 이지롤 로그인 화면이 열리면 이지롤 앱 계정(이메일·비밀번호)으로 로그인

    4. 등록된 블라인드가 SmartThings [기기] 탭에 자동으로 나타나면 완료!

      💡 블라인드는 "[Inoshade] 1(거실)" 처럼 "[Inoshade] 번호(구역 이름)" 형식의 이름으로 들어오고, 처음에는 "지정된 방 없음" 에 놓입니다. 기기 화면 우측 상단 ⋮ 에서 이름을 "거실 블라인드"처럼 부르기 쉽게 바꾸고 원하는 방(거실 등)에 배치해 두면, 빅스비 음성과 루틴에서 더 잘 알아듣습니다.

    💡 이지롤 앱에 등록된 모든 블라인드가 한 번에 SmartThings에 추가됩니다(내 계정에 등록한 블라인드만 — 공유받은 블라인드 제외). 나중에 블라인드를 더 등록하면 SmartThings에도 자동으로 추가돼요(반영까지 최대 하루 정도 걸릴 수 있어요).

    💡 전에 SmartThings에 연동해 두셨던 분은 그대로 계속 사용하실 수 있습니다.

    이렇게 쓸 수 있어요

    방법 예
    SmartThings 카드 닫기/일시정지/열림, 위치 % 조절, 프리셋 m1·m2·m3
    빅스비 음성 "하이 빅스비, 거실 블라인드 열어줘" / "블라인드 반만 열어줘" / "블라인드 닫아줘"
    루틴(자동화) 취침 모드에 블라인드 닫기 · 아침 알람과 함께 열기 · 외출 시 전부 닫기 · 일출/일몰에 맞추기
    삼성 가전과 함께 TV를 켜면 블라인드 닫기, 에어컨 켤 때 햇빛 가리기 등 한 루틴에 묶기

    잘 안 될 때

    증상 해결
    목록에 EasyRoll SmartBlind가 안 나옴 목록은 알파벳순이라 E 항목까지 내리거나 🔍 검색창에 "EasyRoll" 입력 → 그래도 없으면 SmartThings 앱을 최신으로 업데이트 후 재시도
    연동했는데 기기가 안 보임 블라인드를 등록한 소유자 계정으로 로그인했는지 확인(구성원으로 공유받은 블라인드는 나타나지 않아요) → 이지롤 앱에서 블라인드가 정상 등록·온라인인지 확인. 새로 등록한 블라인드는 SmartThings에 나타나기까지 최대 하루 정도 걸릴 수 있어요
    카드 조작에 반응이 없음 블라인드가 온라인인지 확인(FAQ) → SmartThings 연동 해제 후 재연동
    SmartThings의 위치 %가 앱과 다름 SmartThings도 이지롤 앱과 같은 기준(100% = 완전 열림)이라 같은 값이 보여야 합니다. 블라인드가 멈춘 뒤 잠시 기다리거나 기기 화면을 새로고침해 보고, 계속 다르면 상/하단 설정을 확인한 뒤 연동을 해제했다가 다시 연결하세요
    슬라이더가 0/100만 됨 블라인드의 상/하단 설정이 안 된 상태 → 2-1. 상/하단 위치 설정
