# Google Home 연동

이지롤 블라인드를 **구글 홈**에 연결하면, 구글 네스트 스피커·안드로이드폰에서 **"헤이 구글" 음성**으로 블라인드를 작동할 수 있습니다.

---

## 준비물

- 이지롤 앱에 **블라인드가 등록된 계정** ([기기 등록하기](../easyroll/02_앱_등록하기.md) 완료 상태)
- 스마트폰에 **Google Home 앱** 설치 + 구글 계정 로그인

## 연결하기 (처음 한 번)

1. **Google Home 앱** → 우측 상단 **[＋] 버튼** → **[＋ 기기]**
2. QR코드 촬영 화면 하단의 **[＋ 다른 방법으로 추가]** → **브랜드 또는 기기 검색**에서 **"EasyRoll"** 검색
3. **이지롤 계정으로 로그인** → 연동 허용
4. 등록된 블라인드가 구글 홈에 나타나면 **방(거실 등)에 배치**하면 완료!

## 이렇게 쓸 수 있어요

| 방법 | 예 |
|---|---|
| **음성 명령** | "헤이 구글, 거실 블라인드 열어줘" / "블라인드 닫아줘" / "블라인드 50%로 해줘" |
| **Google Home 앱** | 기기 카드에서 열기/닫기·위치 조절 |
| **루틴** | "좋은 아침" 루틴에 블라인드 열기, 취침 루틴에 닫기 등 |

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 검색해도 EasyRoll이 안 나옴 | Google Home 앱을 최신으로 업데이트 후 재시도 |
| 연동했는데 기기가 안 보임 | 이지롤 앱에서 블라인드가 정상 등록·온라인인지 먼저 확인 |
| 음성 명령에 반응이 없음 | 기기 이름(구글 홈에서 부르는 이름)을 확인 — 짧고 부르기 쉬운 이름 추천 |
| 동작이 안 됨 | 블라인드가 온라인인지 확인([FAQ](../easyroll/06_문제해결_FAQ.md)) → 연동 해제 후 재연동 |
