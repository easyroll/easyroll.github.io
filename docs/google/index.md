# Google Home 연동

이지롤 스마트블라인드를 **구글 홈(Google Home)** 에 연결하면, 구글 네스트 스피커·네스트 허브·안드로이드폰에서 **"헤이 구글" 음성**으로 블라인드를 작동하고, 구글 홈 앱의 **루틴**에 넣어 자동으로 움직이게 할 수 있습니다.

---

## 지원되는 기능

| 기능 | Google Home에서 |
|---|---|
| **열기 · 닫기** | 음성 / 구글 홈 앱 기기 카드 / 루틴 |
| **원하는 위치(%)로** | "블라인드 30%로 열어줘", "반만 열어줘" — 슬라이더로도 조절 (**100% = 완전 열림**, 구글 기준) |
| **위치 표시** | 구글 홈 앱 카드에 위치가 표시되지만 **구글로 마지막에 움직인 위치** 기준이에요 — 이지롤 앱·리모컨·알람(예약)으로 움직인 뒤에는 실제와 다를 수 있고, 전원이 꺼져도 "오프라인"으로 표시되지 않아요. 정확한 상태는 **이지롤 앱**에서 확인하세요 |
| **루틴** | "좋은 아침"에 열기, 취침 루틴에 닫기, 일출·일몰에 맞추기 등 |

> ⚠️ **"정지" 음성 명령은 지원되지 않습니다.** 움직이는 블라인드를 멈추려면 이지롤 앱이나 리모컨의 **■ 정지**를 사용하세요.

---

## 준비물

- 이지롤 앱에 **블라인드가 등록된 계정** ([기기 등록하기](../easyroll/02_앱_등록하기.md) 완료 상태)
- 블라인드를 **직접 등록한(소유자) 계정**으로 연결하세요 — [구성원](../easyroll/10_구성원_추가.md)으로 공유받은 블라인드는 연동되지 않습니다.
- 스마트폰에 **Google Home 앱** 설치 + 구글 계정 로그인
- 블라인드가 **인터넷(집 WiFi)에 연결**된 상태 — 구글 홈 연동은 이지롤 서버를 통해 동작합니다
- 위치(%) 명령을 정확히 쓰려면 블라인드의 **상/하단 설정**이 되어 있어야 합니다 ([2-1. 상/하단 위치 설정](../easyroll/02-1_상하단_위치_설정.md))

## 연결하기 (처음 한 번)

1. **Google Home 앱** → 우측 상단 **[＋]** → **[＋ 기기]**
2. QR코드 촬영 화면 하단의 **[＋ 다른 방법으로 추가]** → **브랜드 또는 기기 검색**에서 **"EasyRoll"** 검색
3. **이지롤 계정으로 로그인**
4. 등록된 블라인드가 구글 홈에 나타나면 **방(거실 등)에 배치**하면 완료!

> 💡 이지롤 앱에 등록된 **모든 블라인드가 한 번에** 구글 홈에 추가됩니다(내 계정에 등록한 블라인드만 — 공유받은 블라인드 제외). 나중에 블라인드를 더 등록했는데 구글 홈에 안 보이면, 구글 홈 앱에서 **"헤이 구글, 기기 동기화해줘"** 라고 말하거나 연동을 한 번 새로고침하세요.
>
> 💡 블라인드 **이름을 짧게**(예: "거실 블라인드") 지어 두면 음성 명령이 잘 알아듣습니다. 이름은 구글 홈 앱의 기기 설정에서 바꿀 수 있어요.

## 이렇게 쓸 수 있어요

| 방법 | 예 |
|---|---|
| **음성 명령** | "헤이 구글, 거실 블라인드 열어줘" / "블라인드 닫아줘" / "블라인드 반만 열어줘" / "블라인드 30%로 열어줘" |
| **방 단위로** | 한 방에 여러 대를 두면 "헤이 구글, 거실 블라인드 다 닫아줘" 처럼 **한 번에** 움직입니다 |
| **Google Home 앱 · 네스트 허브** | 기기 카드에서 열기/닫기·위치 슬라이더 |
| **루틴** | "좋은 아침" 루틴에 블라인드 열기, "잘 자" 루틴에 닫기, 외출 루틴에 전부 닫기, 일출·일몰 시각에 맞추기 |

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 검색해도 EasyRoll이 안 나옴 | Google Home 앱을 최신으로 업데이트 후 재시도 |
| 연동했는데 기기가 안 보임 | 블라인드를 등록한 **소유자 계정**으로 로그인했는지 확인(구성원으로 공유받은 블라인드는 나타나지 않아요) → 이지롤 앱에서 블라인드가 정상 등록·온라인인지 확인 → "헤이 구글, 기기 동기화해줘" |
| 음성 명령에 반응이 없음 | 기기 이름(구글 홈에서 부르는 이름)을 확인 — 짧고 부르기 쉬운 이름 추천. 방 이름과 겹치지 않게 |
| "블라인드 50%로" 가 안 먹음 | 블라인드의 **상/하단 설정**이 안 된 상태 → [2-1. 상/하단 위치 설정](../easyroll/02-1_상하단_위치_설정.md) |
| 구글 홈에 보이는 위치가 실제와 다름 | 구글 홈 카드는 **구글로 마지막에 움직인 위치**를 보여 줘서, 이지롤 앱·리모컨·알람(예약)으로 움직인 뒤에는 실제와 다르게 보일 수 있어요. 정확한 위치는 **이지롤 앱**에서 확인하세요. (구글 홈도 이지롤 앱과 같이 **100% = 완전 열림** 기준이에요) |
| 동작이 안 됨 | 블라인드가 온라인인지 확인([FAQ](../easyroll/06_문제해결_FAQ.md)) → 연동 해제 후 재연동 |
