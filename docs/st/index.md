# SmartThings 연동

이지롤 블라인드를 **삼성 SmartThings**에 연결하면, 갤럭시폰·삼성 가전과 한 화면에서 제어하고 **빅스비 음성**으로도 작동할 수 있습니다.

---

## 준비물

- 이지롤 앱에 **블라인드가 등록된 계정** ([기기 등록하기](../easyroll/02_앱_등록하기.md) 완료 상태)
- 스마트폰에 **SmartThings 앱** 설치 + 삼성 계정 로그인

## 연결하기 (처음 한 번)

1. **SmartThings 앱** → **[+ 기기 추가]**
2. **[파트너 기기(연동 서비스)]** → **"EasyRoll"** 검색
3. **이지롤 계정으로 로그인** → 연동 허용
4. 등록된 블라인드가 SmartThings에 **자동으로 나타나면 완료!**

> 연동 후에는 블라인드를 움직이면 SmartThings 카드의 위치(%)도 **자동으로 함께 갱신**됩니다.

## 이렇게 쓸 수 있어요

| 방법 | 예 |
|---|---|
| **SmartThings 카드** | 열기/닫기/정지, 위치 % 조절 |
| **빅스비 음성** | "하이 빅스비, 거실 블라인드 열어줘" / "블라인드 반만 열어줘" |
| **자동화(루틴)** | 취침 모드에 블라인드 닫기, 아침 알람과 함께 열기 등 |

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 검색해도 EasyRoll이 안 나옴 | SmartThings 앱을 최신으로 업데이트 후 재시도 |
| 연동했는데 기기가 안 보임 | 이지롤 앱에서 블라인드가 정상 등록·온라인인지 먼저 확인 |
| 카드 조작에 반응이 없음 | 블라인드가 온라인인지 확인([FAQ](../easyroll/06_문제해결_FAQ.md)) → SmartThings 연동 해제 후 재연동 |
