# 이지롤 × Home Assistant 연동 가이드

이지롤 스마트 블라인드를 **Home Assistant**에 연결하면,
클라우드 없이 집 안에서 직접 제어하고 HA 자동화(일출/일몰·온도 연동 등)에 활용할 수 있습니다.
이지롤 앱은 그대로 쓰면서 HA를 **추가로** 연결하는 **하이브리드 방식을 권장**합니다 — 인터넷 연결이 안 돼도 HA에서 로컬 제어 가능, HA가 꺼져도 인터넷이 연결되어 있으면 앱에서 계속 제어됩니다.

## 빠른 시작

1. HA에 **Mosquitto broker** 애드온 설치 → [준비물 확인](01_시작하기_준비물.md)
2. 이지롤 **앱으로 기기 등록** (이미 쓰고 있으면 생략) → [기기 등록하기](../easyroll/02_앱_등록하기.md)
3. 앱에서 구역 이름 옆 ⚙ → **[구역 기기 설정] → [Home Assistant 연결]** → 기기 선택 + 브로커 정보 입력 → **[연결하기]** → [상세](02_기기_연결하기.md)
4. HA에 자동 등록 완료 — **앱과 HA 모두** 바로 사용!

## 특징

- **로컬 연결** — 인터넷이 끊겨도 집 안에서 동작
- **자동 등록** (MQTT Discovery) — YAML 수동 작성 불필요
- **온라인/오프라인 자동 표시**
- **앱 + HA 동시 사용(하이브리드)** — **이지롤 전용 앱과 HA에서 동시에 제어 가능.** 인터넷 연결이 안 돼도 HA에서 로컬 제어 가능, HA가 꺼져도 인터넷이 연결되어 있으면 앱에서 계속 제어됩니다. (펌웨어 V3.2.0 이상)
