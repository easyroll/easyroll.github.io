# 이지롤 × Home Assistant 연동 가이드

이지롤 스마트 블라인드를 **Home Assistant**에 연결하면,
클라우드 없이 집 안에서 직접 제어하고 HA 자동화(일출/일몰·온도 연동 등)에 활용할 수 있습니다.

## 빠른 시작

1. HA에 **Mosquitto broker** 애드온 설치 → [준비물 확인](01_시작하기_준비물.md)
2. 블라인드 전원 ON → 폰으로 기기 WiFi 접속 → `192.168.4.1` → **[Home Assistant]** 선택 → [상세](02_기기_연결하기.md)
3. HA에 자동 등록 완료 — 바로 사용!

## 특징

- **로컬 연결** — 인터넷이 끊겨도 집 안에서 동작
- **자동 등록** (MQTT Discovery) — YAML 수동 작성 불필요
- **온라인/오프라인 자동 표시**
