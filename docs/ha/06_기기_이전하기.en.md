# Moving / Removing a Device

How to **move a device that was connected to HA to another home, router or HA**, or remove it cleanly from HA.
The procedure depends on the connection mode — a **Hybrid (app + HA)** device only needs to be deleted in the app, while an **HA-only** device is reset with a single command.

!!! info "Firmware required — V3.2.0 or later"

    The procedures below (automatic HA cleanup on app deletion, `EZS_HARESET$`) work on firmware **V3.2.0 or later**.
    Check the version in the app under **Device info → Firmware version**, or with the `EZS_VER$` command. If it's lower, update first via [7. Device Update](../easyroll/09_기기_업데이트.md).

---

## Hybrid (app + HA) device — just delete it in the app

1. In the EasyRoll app, tap **⚙** next to the zone name → **delete** the device (or delete the zone)
2. The device receives the deletion notice, **cleans up its HA registration by itself**, clears its Wi-Fi/HA settings and restarts → it returns to **setup AP mode (`EZS...` Wi-Fi)**.
3. The device **disappears from HA within seconds** (no ghost "unavailable" device is left behind).

> 💡 If the device was **powered off** at the moment of deletion, it cleans itself up within **3–4 minutes** after it is next powered on.
> 💡 If you only want to disconnect HA and **keep using the app**, use [Home Assistant 연결 해제](02_기기_연결하기.md) (Disconnect) instead of deleting.

### Reconnecting at the new location

Since the device is back in AP mode, simply start over with **Method ①** in [2. Connecting the Device](02_기기_연결하기.md):
[register the device](../easyroll/02_앱_등록하기.md) with the EasyRoll app (new Wi-Fi) → ⚙ → **[구역 기기 설정] → [Home Assistant 연결]** and enter the new HA broker info.

---

## HA-only device — `EZS_HARESET$`

A device used with HA only (never registered in the app) is reset with a single command from HA. (Use the same command when you want to move a device while keeping its server registration.)

!!! note "If you sent it to a device that was registered in the app"

    The server-side registration is not removed, so the device **stays in the app as 'offline'.** (For a Hybrid device, simply **deleting it in the app** is the easier route.)

    - **To keep using it in the same home**: connect to the device Wi-Fi (`EZS...`) and re-enter just the router info to bring it back to the app → reconnect HA with **[Home Assistant 연결]**
    - **To move it to another site**: also **delete the device in the app**

Send the command from the same place as in [4. Advanced Commands](04_고급_명령어.md) — **"Where to send commands"**.

!!! warning "In HA, commands start with `EZS_`, not `#`"

    It's **`EZS_HARESET$`**, not `#HARESET$`.

1. In HA, go to **Settings → Devices & Services → MQTT → ⚙ Configure → Publish a packet** and send:

| Field | Value |
|---|---|
| Topic | `/<device ID>` — e.g. `/EZS16J1234567` |
| Payload | `EZS_HARESET$` |

2. The device replies with **`ha_reset:ok`** on `/feedback`, then **restarts automatically** a few seconds later.
3. After restarting, the device **disappears cleanly from HA** and returns to **setup AP mode (`EZS...` Wi-Fi)**.

### Reconnecting at the new location

- **Switch to Hybrid ★Recommended** — [register the device](../easyroll/02_앱_등록하기.md) with the EasyRoll app → ⚙ → **[구역 기기 설정] → [Home Assistant 연결]** (Method ①)
- **Stay HA only** — connect your phone to the device Wi-Fi (`EZS...`) → open `192.168.4.1` in a browser → **[Home Assistant]** → enter the new home Wi-Fi + new HA broker info → **[Save and Connect]** (Method ②-B)

---

!!! success "Upper/lower limits and the current position are NOT erased"

    Both app deletion and `EZS_HARESET$` clear **only the Wi-Fi/HA connection info**.
    The **upper/lower positions stored in the motor are kept**, so you **don't need to set the limits again** after reinstalling.

## Comparison — which method should I use?

| Situation | Method | Connection | Limit settings |
|---|---|---|---|
| Temporarily hide from the HA screen | `EZS_HADISCOVERY_OFF$` | **Kept** (restore anytime with `EZS_HADISCOVERY$`) | Kept |
| Drop HA but keep the app (Hybrid) | App **[Home Assistant 연결 해제]** | Switches to app only; HA registration cleaned up automatically | Kept |
| Move to another home/HA — Hybrid device | **Delete the device in the app** | Cleared → back to AP mode; HA cleaned up automatically | **Kept** |
| Move to another home/HA — HA-only device | `EZS_HARESET$` | Cleared → back to AP mode | **Kept** |
| Full factory reset | Hold device button 5s | Cleared → default (EasyRoll app) state | Kept |
