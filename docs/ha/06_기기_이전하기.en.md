# Moving / Removing a Device (Clear HA Connection)

Use this reset when you want to **move a device that was connected to Home Assistant to another home, another router, or another HA**.
It removes the device cleanly from HA and returns it to a state where you can set it up from scratch at the new location.

!!! info "Firmware required — V3.2.0T2 or later"

    This feature (`EZS_HARESET$`) only works on firmware **V3.2.0T2 or later**.
    Check the version with the `EZS_VER$` command. If it's lower, update first via [7. Device Update](../easyroll/09_기기_업데이트.md).

---

## When to use it

- When you **uninstall an HA-connected blind and reinstall it in another home/office**
- When you want to **completely change the router (Wi-Fi) or HA (broker)** and reconnect from scratch
- When you want to remove the device from HA **without leaving a ghost "unavailable" device behind**

> 💡 If you only want to hide it from the HA screen for a while (keeping the connection), use `EZS_HADISCOVERY_OFF$` instead of a reset. → see the [comparison table](#comparison-which-command-should-i-use) below

---

## How to reset

Send the command from the same place as in [4. Advanced Commands](04_고급_명령어.md) — **"Where to send commands"**.

!!! warning "In HA, commands start with `EZS_`, not `#`"

    It's **`EZS_HARESET$`**, not `#HARESET$`.

1. In HA, go to **Settings → Devices & Services → MQTT → ⚙ Configure → Publish a packet** and send:

| Field | Value |
|---|---|
| Topic | `/<device ID>` — e.g. `/EZS16J1234567` |
| Payload | `EZS_HARESET$` |

2. The device replies with **`ha_reset:ok`** on `/feedback`, then **restarts automatically** a few seconds later.
3. After restarting, the device **disappears cleanly from HA** and returns to **setup AP mode (`EZS...` Wi-Fi)**.

---

## Reconnecting at the new location

Since the device is back in AP mode, set it up at the new home/office from the start as in [2. Connecting the Device](02_기기_연결하기.md).

- **Hybrid (app + HA) ★Recommended** — [register the device](../easyroll/02_앱_등록하기.md) with the EasyRoll app (new Wi-Fi) → at `http://<blind IP>:20318/hasetup` enter the new HA info + **tick [Easyroll 앱과 함께 사용]** → save (Method ①)
- **HA only** — connect your phone to the device Wi-Fi (`EZS...`) → open `192.168.4.1` → **[Home Assistant]** → enter the new home Wi-Fi + new HA broker info → **[Save and Connect]** (Method ②)

!!! success "Upper/lower limits and the current position are NOT erased"

    `EZS_HARESET$` clears **only the Wi-Fi/HA connection info**.
    The **upper/lower positions stored in the motor are kept**, so you **don't need to set the limits again** after reinstalling.

---

## Comparison — which command should I use?

| Situation | Method | Connection | Limit settings |
|---|---|---|---|
| Temporarily hide from the HA screen | `EZS_HADISCOVERY_OFF$` | **Kept** (restore anytime with `EZS_HADISCOVERY$`) | Kept |
| Move to another home/HA *(this page)* | `EZS_HARESET$` | **Cleared → back to AP mode** | **Kept** |
| Full factory reset | Hold device button 5s | Cleared → default (EasyRoll app) state | Kept |
