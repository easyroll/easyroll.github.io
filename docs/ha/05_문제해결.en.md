# 5. Troubleshooting (HA)

---

## Stuck at the connection step

| Symptom | Check |
|---|---|
| EZS... doesn't appear in the Wi-Fi list | Reconnect power and wait 1 minute. If it's an already-registered device, hold the button 5 seconds (reset) and retry |
| 192.168.4.1 won't open | Make sure your phone is connected to the **device Wi-Fi (EZS...)** (not your home Wi-Fi). Turn off mobile data briefly |
| Saved, but the device doesn't show up in HA | ① Are the blind and HA on the **same router**? ② Any typo in the broker IP/port/account? ③ Is the Mosquitto add-on running? |
| No MQTT integration at all | Add the MQTT integration in HA + install the Mosquitto add-on first ([1. Requirements](01_시작하기_준비물.md)) |

## Problems during use

| Symptom | Check |
|---|---|
| Card exists but shows "Unavailable" | Check the device power/Wi-Fi. If the device LED blinks at 3-second intervals, it's reconnecting — wait a moment. On a Hybrid device where the app still works, see **App works but HA doesn't** below |
| Slider only does 0/100 | The device's **Upper/Lower Limit Setup** isn't done — it works normally after setup ([2-1. Set Upper/Lower Limits](../easyroll/02-1_상하단_위치_설정.md); for devices without the app, [②-B Step 4](02_기기_연결하기.md#step-4--upperlower-limit-setup--do-this-first)) |
| Entity disappeared | Send `EZS_HADISCOVERY$` to re-register ([4. Advanced Commands](04_고급_명령어.md)) |
| No response when sending a command | Check that the command starts with `EZS_` and the topic is `/<device ID>` |
| App works but HA doesn't (Hybrid) | Check that the HA broker (Mosquitto) is running and that the HA machine's IP hasn't changed. The device keeps retrying, so it recovers automatically once the broker is back. **If the IP changed**, run ⚙ → [Zone device settings] → **[Home Assistant]** again in the app with the new address (a fixed IP for the HA server is recommended) |
| HA doesn't work (HA-only) — the HA machine's IP changed | Re-save on `http://<blind IP>:20318/hasetup` with the new broker IP and **without the checkbox**. How to find the blind's IP, and the reset route, are in [2. Connecting the Device · Good to know](02_기기_연결하기.md#good-to-know) |
| HA works but the app doesn't (Hybrid) | Check the internet (router WAN) connection. It recovers automatically once the internet is back — meanwhile you can still control via HA |
| No **[Home Assistant]** menu under [Zone device settings] in the app | It is shown **only to the device owner account** (shared member accounts can't see it). Also make sure the app is up to date |
| Device info shows "**Not supported on this device**" | Firmware below V3.2.0 → do [7. Device Update](../easyroll/09_기기_업데이트.md) and retry |
| Result shows "**Cannot reach**" / "**Login failed**" / "**No response**" | In order: check broker address, port and that the broker is running / check the MQTT account and password / check device power and Wi-Fi — "**No response**" also appears when the firmware is **below V3.2.0** (the Home Assistant item in Device info shows "Not used"). Check the firmware in [Device info] and do [7. Device Update](../easyroll/09_기기_업데이트.md), then retry. **Failed devices are left unchanged**, so fix the input and retry |

## What happens to the device when HA (the broker) goes down?

Even if the broker briefly disappears due to a NAS reboot, HA update, etc., there's nothing to worry about:

- The device **keeps trying to reconnect automatically**, and **reconnects on its own** when the broker returns.
- Meanwhile, the **remote and buttons still work normally.**
- On an **HA-only device**, if the LED **blinks once every 3 seconds**, that indicates "reconnecting."
- On a **Hybrid (app + HA) device**, the **LED doesn't change** when HA goes down, and you keep control via the app. (On a Hybrid device, the 3-second blink means it is reconnecting to the internet (server).)

## I changed my Wi-Fi router

If you only changed the router, there's no need to reset — just **wait for the device to return to setup mode (AP) on its own.**

Wait 1–2 minutes until an **`EZS...` network reappears** in your phone's Wi-Fi list. (Don't unplug it — a power cycle restarts the attempts and makes it take longer.)

- **Hybrid (app + HA) device** — just set the **new Wi-Fi** with the EasyRoll app's [Changing the Wi-Fi Router](../easyroll/08_공유기_변경.md). The saved HA settings stay, so it reconnects to HA as well. (If the **HA machine's IP also changed** with the new router, only HA silently drops — run **[Zone device settings] → [Home Assistant]** again in the app with the new address. A fixed IP for the HA server is recommended.)
- **HA-only device** — connect to that `EZS...` Wi-Fi → open **`192.168.4.1`** in a browser → **[Home Assistant]** → enter the **new home Wi-Fi + HA broker info** → **[저장하고 연결]** (Save and Connect) (for the fields, see Method ②-B in [2. Connecting the Device](02_기기_연결하기.md))

> 💡 ★Upper/lower limits and the current position are kept in every case, so **no need to set the limits again.**

## I deleted the device from HA and now the LED is blinking

On an **HA-only device**, if you delete the device's account from HA (Mosquitto), the device is refused a connection and enters **Setup Mode (LED blinks 3 times).**

- To use it again: restore the account and wait a moment for it to **return automatically**, or re-set it up via Method ②-B in [2. Connecting the Device](02_기기_연결하기.md).
- To go back to the EasyRoll app: hold the device button 5 seconds (reset), then register in the EasyRoll app.

On a **Hybrid (app + HA) device**, deleting the HA account **doesn't change the LED or put it into Setup Mode** — only the HA connection drops, and the app keeps working.

- To use HA again: restore the account and it reconnects automatically. To use a different account, run ⚙ → [Zone device settings] → **[Home Assistant]** again in the app. (No reset or ②-B setup is needed — saving via ②-B would switch the device to HA only.)

> 💡 To move it to another home/HA: for a Hybrid device, simply **delete the device in the app** and it disappears from HA automatically. For an HA-only device, use `EZS_HARESET$` → [Move / Remove Device](06_기기_이전하기.md) *(V3.2.0 or later)*

## I want to revert to the EasyRoll app

- **Hybrid device**: in the app, ⚙ → **[Zone device settings] → [Home Assistant]** → select the devices → **[Disconnect from Home Assistant]**
- **HA-only device**: **[Easyroll_Server로 복원]** (Restore Easyroll_Server) on the device setup page `http://<blind IP>:20318/hasetup` — or reset the device (hold the button 5 s) and register it in the app
    - Neither of these **removes the device from HA.** Delete the blind (EZS...) yourself in HA under **Settings → Devices & services → MQTT**. ([Details](02_기기_연결하기.md#reverting-to-the-easyroll-app))
