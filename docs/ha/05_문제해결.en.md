# 5. Troubleshooting (HA)

---

## Stuck at the connection step

| Symptom | Check |
|---|---|
| EZS... doesn't appear in the Wi-Fi list | Reconnect power and wait 1 minute. If it's an already-registered device, hold the button 5 seconds (reset) and retry |
| 192.168.4.1 won't open | Make sure your phone is connected to the **device Wi-Fi (EZS...)** (not your home Wi-Fi). Turn off mobile data briefly |
| Saved, but the device doesn't show up in HA | ① Are the blind and HA on the **same router**? ② Any typo in the broker IP/port/account? ③ Is the Mosquitto add-on running? |
| No MQTT integration at all | Add the MQTT integration in HA + install the Mosquitto add-on first ([1. Requirements](01_시작하기_준비물.md)) |

## Problems during use

| Symptom | Check |
|---|---|
| Card exists but shows "Unavailable" | Check the device power/Wi-Fi. If the device LED blinks at 3-second intervals, it's reconnecting — wait a moment |
| Slider only does 0/100 | The device's **Upper/Lower Limit Setup** isn't done — it works normally after setup |
| Entity disappeared | Send `EZS_HADISCOVERY$` to re-register ([4. Advanced Commands](04_고급_명령어.md)) |
| No response when sending a command | Check that the command starts with `EZS_` and the topic is `/<device ID>` |
| App works but HA doesn't (Hybrid) | Check that the HA broker (Mosquitto) is running and that the HA machine's IP hasn't changed. The device keeps retrying, so it recovers automatically once the broker is back. **If the IP changed**, run ⚙ → [구역 기기 설정] → **[Home Assistant 연결]** again in the app with the new address (a fixed IP for the HA server is recommended) |
| HA works but the app doesn't (Hybrid) | Check the internet (router WAN) connection. It recovers automatically once the internet is back — meanwhile you can still control via HA |
| The [Home Assistant 연결] menu isn't in the app | It is shown **only to the device owner account** (shared member accounts can't see it). Also make sure the app is up to date |
| Device info shows "지원하지 않는 기기" (Unsupported device) | Firmware below V3.2.0 → do [7. Device Update](../easyroll/09_기기_업데이트.md) and retry |
| Result shows "서버 연결 불가" / "계정 오류" / "응답 없음" | In order: check broker address, port and that the broker is running / check the MQTT account and password / check device power and Wi-Fi. **Failed devices are left unchanged**, so fix the input and retry |

## What happens to the device when HA (the broker) goes down?

Even if the broker briefly disappears due to a NAS reboot, HA update, etc., there's nothing to worry about:

- The device **keeps trying to reconnect automatically**, and **reconnects on its own** when the broker returns.
- Meanwhile, the **remote and buttons still work normally.**
- If the device LED **blinks once every 3 seconds**, that indicates "reconnecting."

## I changed my Wi-Fi router

If you only changed the router, there's no need to reset — just **wait for the device to return to setup mode (AP) on its own.**

Wait 1–2 minutes until an **`EZS...` network reappears** in your phone's Wi-Fi list. (Unplug/replug power to make it appear faster.)

- **Hybrid (app + HA) device** — just set the **new Wi-Fi** with the EasyRoll app's [Changing the Wi-Fi Router](../easyroll/08_공유기_변경.md). The saved HA settings stay, so it reconnects to HA as well. (If the **HA machine's IP also changed** with the new router, only HA silently drops — run **[Home Assistant 연결]** again in the app with the new address. A fixed IP for the HA server is recommended.)
- **HA-only device** — connect to that `EZS...` Wi-Fi → open **`192.168.4.1`** in a browser → **[Home Assistant]** → enter the **new home Wi-Fi + HA broker info** → **[Save and Connect]** (for the fields, see Method ②-B in [2. Connecting the Device](02_기기_연결하기.md))

> 💡 ★Upper/lower limits and the current position are kept in every case, so **no need to set the limits again.**

## I deleted the device from HA and now the LED is blinking

If you delete the device's account from HA (Mosquitto), the device is refused a connection and enters **Setup Mode (LED blinks 3 times).**
- To use it again: restore the account and wait a moment for it to **return automatically**, or re-set it up via Method ②-B in [2. Connecting the Device](02_기기_연결하기.md).
- To go back to the EasyRoll app: hold the device button 5 seconds (reset), then register in the EasyRoll app.
- To move it to another home/HA: for a Hybrid device, simply **delete the device in the app** and it disappears from HA automatically. For an HA-only device, use `EZS_HARESET$` → [Move / Remove Device](06_기기_이전하기.md) *(V3.2.0 or later)*

## I want to revert to the EasyRoll app

- While connected to HA, send `EZS_MQTTAWS$` ([4. Advanced Commands](04_고급_명령어.md)) — or reset the device and register it in the app.
- To drop **just HA and keep the app** from Hybrid, the easiest way is in the app: ⚙ → **[구역 기기 설정] → [Home Assistant 연결]** → select the devices → **[Home Assistant 연결 해제]** (Disconnect). (The same command, or **[Easyroll_Server로 복원]** on `.../20318/hasetup`, also works.)
