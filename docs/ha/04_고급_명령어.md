# 4. 고급 명령어 (MQTT 직접 제어)

카드 버튼만으로 충분하다면 이 장은 건너뛰어도 됩니다.
세부 설정·진단이 필요한 고급 사용자를 위한 내용입니다.

---

## 명령 보내는 곳

**설정** → **기기 및 서비스** → **MQTT** → (Mosquitto 줄의) **⚙ 구성** 으로 들어가면
아래 두 가지 도구를 쓸 수 있습니다.

### 명령 보내기 — 패킷 발행(Publish a packet)

| 입력 항목 | 값 |
|---|---|
| 토픽(Topic) | `/<기기ID>` — 예: `/EZS16A4106036` |
| 페이로드(Payload) | 보낼 명령 — 예: `EZS_5U0$` |

### 응답 보기 — 토픽 듣기(Listen to a topic)

| 입력 항목 | 값 |
|---|---|
| 토픽(Topic) | `#` (전체 듣기) |

> 💡 기기의 응답이 HA로 오는 것은 **HA 전용 기기**뿐입니다. 대부분 **`/feedback`** 토픽으로, 펌웨어 버전(`EZS_VER$`)은 **`/version/<기기ID>`** 토픽으로 올라옵니다.

> 💡 **하이브리드(앱 + HA) 기기**는 조회 명령의 응답이 이지롤 서버로 가므로 HA에는 보이지 않습니다. 버전·상태는 이지롤 앱 ⚙ → **[구역 기기 설정] → [기기 정보]** 에서 확인하세요. 위치는 HA 카드와 `/<기기ID>/pos` 에 반영됩니다.

---

## 명령 규칙

!!! warning "모든 명령은 `EZS_` 로 시작합니다"

    HA에서 보내는 명령은 반드시 **`EZS_`** 로 시작해야 합니다.

## 자주 쓰는 명령

| 명령 | 동작 |
|---|---|
| `EZS_5U0$` / `EZS_5D0$` / `EZS_5S0$` | 열기 / 닫기 / 정지 |
| `EZS_AL050.000$` | 지정 % 위치로 이동 — **000.000 = 맨 위(완전 열림) ~ 100.000 = 맨 아래(완전 닫힘)**. HA 슬라이더 %와 반대입니다 (예: HA 70% 열림 = `EZS_AL030.000$`) |
| `EZS_POS$` | 현재 위치 조회 — 응답의 `pct`와 `/<기기ID>/pos` 값도 같은 기준(0 = 맨 위) |
| `EZS_VER$` | 펌웨어 버전 조회 — 응답 토픽 `/version/<기기ID>` |
| `EZS_RSS$` | WiFi 신호 세기 조회 (연결 문제 진단에 유용) |
| `EZS_5G1$` ~ `EZS_5G4$` | 저장 위치 1~4로 이동 |
| `EZS_5g1$` ~ `EZS_5g4$` | 현재 위치를 1~4에 저장 |
| `EZS_HADISCOVERY$` | HA에 기기 다시 등록 (엔티티가 사라졌을 때) |
| `EZS_HADISCOVERY_OFF$` | HA에서 기기 등록 제거 |
| `EZS_MQTTINFO$` | 현재 연결 정보 조회 — HA 전용 기기: `mode:ha`, 브로커 주소·포트·계정 (비밀번호는 제외) |
| `EZS_HAJOG$` / `EZS_HAJOG_OFF$` | HA 카드의 짧게 올림/내림(jog) 버튼 표시 / 숨김 (기본 숨김) |
