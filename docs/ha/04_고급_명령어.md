# 4. 고급 명령어 (MQTT 직접 제어)

카드 버튼만으로 충분하다면 이 장은 건너뛰어도 됩니다.
세부 설정·진단이 필요한 고급 사용자를 위한 내용입니다.

---

## 명령 보내는 곳

**설정** → **기기 및 서비스** → **MQTT** → (Mosquitto 줄의) **⚙ 구성** 으로 들어가면
아래 두 가지 도구를 쓸 수 있습니다.

### 명령 보내기 — 패킷 발행(Publish a packet)

| 입력 항목 | 값 |
|---|---|
| 토픽(Topic) | `/<기기ID>` — 예: `/EZS16A4106036` |
| 페이로드(Payload) | 보낼 명령 — 예: `EZS_5U0$` |

### 응답 보기 — 토픽 듣기(Listen to a topic)

| 입력 항목 | 값 |
|---|---|
| 토픽(Topic) | `#` (전체 듣기) |

> 💡 기기의 응답은 **`/feedback`** 토픽으로 올라옵니다.

---

## 명령 규칙

!!! warning "모든 명령은 `EZS_` 로 시작합니다"

    HA에서 보내는 명령은 반드시 **`EZS_`** 로 시작해야 합니다.

## 자주 쓰는 명령

| 명령 | 동작 |
|---|---|
| `EZS_5U0$` / `EZS_5D0$` / `EZS_5S0$` | 열기 / 닫기 / 정지 |
| `EZS_AL050.000$` | 50% 위치로 이동 (000.000~100.000) |
| `EZS_POS$` | 현재 위치 조회 |
| `EZS_VER$` | 펌웨어 버전 조회 |
| `EZS_RSS$` | WiFi 신호 세기 조회 (연결 문제 진단에 유용) |
| `EZS_5G1$` ~ `EZS_5G4$` | 저장 위치 1~4로 이동 |
| `EZS_5g1$` ~ `EZS_5g4$` | 현재 위치를 1~4에 저장 |
| `EZS_HADISCOVERY$` | HA에 기기 다시 등록 (엔티티가 사라졌을 때) |
| `EZS_HADISCOVERY_OFF$` | HA에서 기기 등록 제거 |
| `EZS_MQTTINFO$` | 현재 연결 모드·브로커 정보 조회 (`mode:aws / both / ha`, 비밀번호는 제외) |

## 연결 모드 전환 (앱 전용 ↔ 하이브리드 ↔ HA 전용)

가장 쉬운 방법은 `http://<블라인드IP>:20318/hasetup` 페이지입니다 (체크 여부·복원 버튼 → [2. 기기 연결하기](02_기기_연결하기.md)). 명령으로도 전환할 수 있습니다.

| 지금 상태 | 보낼 명령 | 결과 |
|---|---|---|
| HA 전용 → **하이브리드** | `EZS_MQTTBOTH$` | 저장된 HA 설정은 그대로 두고 이지롤 서버에도 함께 연결 (앱 + HA) |
| 하이브리드 / HA 전용 → **앱 전용** | `EZS_MQTTAWS$` | 이지롤(회사) 서버만 사용 → 이지롤 앱. HA 쪽 등록 흔적은 자동 정리 |
| 앱 전용(이지롤 서버) → **하이브리드** | `#MQTTBOTH$` (이지롤 경로로 전송) — 저장된 HA 설정 재사용. `#MQTTBOTH<ip>,<포트>,<계정>,<비밀번호>$` 로 설정까지 한 번에 가능 | 앱 + HA |
| 앱 전용(이지롤 서버) → **HA 전용** | `#MQTTHA$` (이지롤 경로로 전송) | 저장된 HA 설정으로 HA 전용 전환 |

> 한 번 HA 정보를 저장해 두면 위 명령들로 **재입력 없이 왕복**할 수 있습니다. 하이브리드·`MQTTBOTH`는 펌웨어 **V3.2.0T4 이상**에서 동작합니다.
