# 4. 고급 명령어 (MQTT 직접 제어)

카드 버튼만으로 충분하다면 이 장은 건너뛰어도 됩니다.
세부 설정·진단이 필요한 고급 사용자를 위한 내용입니다.

---

## 명령 보내는 곳

HA 화면: **설정 → 기기 및 서비스 → MQTT → (Mosquitto 줄의) ⚙ 구성**
- **패킷 발행(Publish a packet)**: 명령 전송 — 토픽 `/<기기ID>` (예: `/EZS16A4106036`), 페이로드에 명령
- **토픽 듣기(Listen to a topic)**: 응답 확인 — 토픽 `#` 입력 후 청취 (기기 응답은 `/feedback` 토픽)

## 명령 규칙

> **HA에서 보내는 모든 명령은 `EZS_`로 시작합니다.** (보안 격리 — 일반 `#` 명령은 무시됨)

## 자주 쓰는 명령

| 명령 | 동작 |
|---|---|
| `EZS_5U0$` / `EZS_5D0$` / `EZS_5S0$` | 열기 / 닫기 / 정지 |
| `EZS_AL050.000$` | 50% 위치로 이동 (000.000~100.000) |
| `EZS_POS$` | 현재 위치 조회 |
| `EZS_VER$` | 펌웨어 버전 조회 |
| `EZS_RSS$` | WiFi 신호 세기 조회 (연결 문제 진단에 유용) |
| `EZS_5G1$` ~ `EZS_5G4$` | 저장 위치 1~4로 이동 |
| `EZS_5g1$` ~ `EZS_5g4$` | 현재 위치를 1~4에 저장 |
| `EZS_CHILDLOCK_ON$` / `_OFF$` | 자식 잠금 켜기/끄기 |
| `EZS_HADISCOVERY$` | HA에 기기 다시 등록 (엔티티가 사라졌을 때) |
| `EZS_HADISCOVERY_OFF$` | HA에서 기기 등록 제거 |

## 서버 전환 (이지롤 앱 ↔ HA)

| 지금 어디에 | 보낼 명령 | 결과 |
|---|---|---|
| HA에 연결됨 | `EZS_MQTTAWS$` | 이지롤(회사) 서버로 복귀 → 이지롤 앱 사용 |
| 이지롤 서버에 연결됨 | `#MQTTHA$` (이지롤 경로로 전송) | 저장된 HA 설정으로 재전환 |

> 한 번 HA 정보를 저장해 두면 위 두 명령으로 **재입력 없이 왕복**할 수 있습니다.
