# 1. 시작하기 — Home Assistant 연동 준비물

이지롤 스마트 블라인드는 **Home Assistant(HA)** 에 직접 연결할 수 있습니다.
연결하면 HA 대시보드에서 블라인드를 제어하고, HA 자동화(일출/일몰, 온도 연동 등)에 활용할 수 있습니다.

---

## 어떤 방식인가요?

```
[Home Assistant] ←── 집 안 네트워크(MQTT) ──→ [블라인드]
```

- **클라우드를 거치지 않는 로컬 연결**입니다 — 인터넷이 끊겨도 집 안에서 동작.
- HA의 **MQTT 통합**을 사용하며, 블라인드가 **자동으로 등록**됩니다(별도 코드 작성 불필요).

---

## 준비물 체크리스트

| 항목 | 설명 |
|---|---|
| ✅ Home Assistant | 설치되어 동작 중 (HA OS, 컨테이너 등 무관) |
| ✅ **MQTT 브로커** | HA 애드온 **Mosquitto broker** 권장 (설정 → 애드온에서 설치) |
| ✅ MQTT 사용자 계정 | HA 사용자 1개 (예: `easyroll1`) — 블라인드가 이 계정으로 접속 |
| ✅ 같은 네트워크 | **블라인드와 HA가 같은 공유기**에 연결되어 있어야 함 |
| ✅ 블라인드 펌웨어 | v2.9.7 이상 (웹 설정 방식 지원) |

## 미리 확인해 둘 정보 3가지

연결 단계에서 입력해야 하니 메모해 두세요:

1. **브로커 IP** = HA가 설치된 장비의 IP (예: `192.168.0.14`)
   - HA 화면: 설정 → 시스템 → 네트워크에서 확인
2. **브로커 포트** = 기본 `1883`
3. **MQTT 사용자 / 비밀번호** = 위에서 만든 계정

> ⚠️ HA를 NAS 가상머신 등에 설치한 경우, IP는 **공유기에서 보이는 LAN IP**여야 합니다 (`172.30.x.x` 같은 내부 주소 아님).
