# 3. HA에서 사용하기

연결이 끝나면 HA에 **커버(cover) 엔티티 + 버튼들**이 자동 생성됩니다.

---

## 기기 카드

✍️ (HA 카드 캡처)

| 컨트롤 | 동작 |
|---|---|
| ▲ 열기 | 맨 위로 |
| ▼ 닫기 | 맨 아래로 |
| ■ 정지 | 멈춤 |
| **위치 슬라이더** | 원하는 %로 이동 (**100% = 완전 열림, 0% = 완전 닫힘** — HA 표준) |
| 짧게 올림/내림 버튼 | 미세 조정 |

> ⚠️ 슬라이더 %를 쓰려면 기기의 **상/하단 위치 설정**이 되어 있어야 합니다.
> 미설정 상태면 0/100만 동작합니다. (설정은 이지롤 설명서 [기본 사용법] 참고)

## 온라인/오프라인 표시

- 기기 전원이 꺼지거나 연결이 끊기면 HA에서 **"사용 불가"** 로 표시됩니다 (약 20~30초 후).
- 다시 켜지면 자동으로 **"사용 가능"** 으로 돌아옵니다.

---

## 자동화 활용 예시

HA 자동화에서 다른 cover와 똑같이 사용하면 됩니다.

```yaml
# 예: 일몰 30분 후 거실 블라인드 닫기
automation:
  - alias: "일몰에 블라인드 닫기"
    trigger:
      - platform: sun
        event: sunset
        offset: "00:30:00"
    action:
      - service: cover.close_cover
        target:
          entity_id: cover.ezs16a4______
```

```yaml
# 예: 아침 7시에 70%만 열기
      - service: cover.set_cover_position
        target:
          entity_id: cover.ezs16a4______
        data:
          position: 70
```

활용 아이디어: 일출/일몰 연동, 실내 온도 연동(여름 낮 자동 차광), 외출 모드(모두 닫기), 음성비서(HA 연동된 구글/알렉사) 등.
