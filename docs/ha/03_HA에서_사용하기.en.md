# 3. Using It in HA

Once connected, HA automatically creates a **cover entity + buttons**.

---

## Device card

| Control | Action |
|---|---|
| ▲ Open | To the top |
| ▼ Close | To the bottom |
| ■ Stop | Halt |
| **Position slider** | Move to any % (**100% = fully open, 0% = fully closed** — HA standard) |
| Jog up/down buttons | Fine adjustment — **hidden by default**. Show them with `EZS_HAJOG$` if needed (hide: `EZS_HAJOG_OFF$`, [4. Advanced Commands](04_고급_명령어.md)) |

> ⚠️ To use the slider %, the device's **Upper/Lower Limit Setup** must be done.
> Without it, only 0/100 work. (How to set it: [User Guide 2-1. Set Upper/Lower Limits](../easyroll/02-1_상하단_위치_설정.md) — for HA-only devices without the app, see [2. Connecting the Device ②-B Step 4](02_기기_연결하기.md#step-4--upperlower-limit-setup--do-this-first) or `http://<blind IP>:20318/limitsetup`)

## Online/offline status

- If the device loses power or its connection drops, HA shows it as **"Unavailable"** (after about 1–3 minutes on a Hybrid device, or about 15–45 seconds on an HA-only device).
- When it comes back on, it automatically returns to **"Available"**.

---

## Automation examples

Use it in HA automations just like any other cover.

```yaml
# e.g. Close the living room blind 30 min after sunset
automation:
  - alias: "Close blinds at sunset"
    trigger:
      - platform: sun
        event: sunset
        offset: "00:30:00"
    action:
      - service: cover.close_cover
        target:
          entity_id: cover.ezs16a4______
```

```yaml
# e.g. Open to 70% at 7 AM
      - service: cover.set_cover_position
        target:
          entity_id: cover.ezs16a4______
        data:
          position: 70
```
