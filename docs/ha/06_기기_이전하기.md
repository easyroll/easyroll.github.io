# 기기 이전·삭제하기

HA에 연결했던 기기를 **다른 집·다른 공유기·다른 HA로 옮기거나**, HA에서 깨끗이 지울 때의 방법입니다.
연결 방식에 따라 절차가 다릅니다 — **하이브리드(앱 + HA)** 기기는 앱에서 삭제만 하면 끝나고, **HA 전용** 기기는 명령 한 번으로 초기화합니다.

!!! info "적용 펌웨어 — V3.2.0 이상"

    아래 절차(앱 삭제 시 HA 자동 정리, `EZS_HARESET$`)는 **V3.2.0 이상** 펌웨어에서 동작합니다.
    버전은 앱 **기기 정보 → 펌웨어 버전** 또는 `EZS_VER$` 명령으로 확인하세요. 낮으면 [7. 기기 업데이트](../easyroll/09_기기_업데이트.md)로 먼저 업데이트하세요.

---

## 하이브리드(앱 + HA) 기기 — 앱에서 삭제하면 끝

1. 이지롤 앱에서 구역 이름 옆 **⚙** → 기기 **삭제**(또는 구역 삭제)
2. 기기가 삭제 통지를 받아 **HA 등록을 스스로 정리**하고 WiFi·HA 설정을 지운 뒤 재시작 → **설정용 AP 모드(`EZS...` WiFi)** 로 돌아갑니다.
3. HA에서 기기가 **수 초 안에 사라집니다** ("사용할 수 없음" 유령 기기가 남지 않음).

> 💡 삭제하는 순간 기기가 **꺼져 있었다면**, 다음에 전원을 켠 뒤 **3~4분** 안에 스스로 정리됩니다.
> 💡 HA 연결만 끊고 **앱은 계속 쓰려면** 삭제가 아니라 [Home Assistant 연결 해제](02_기기_연결하기.md)를 쓰세요.

### 새 장소에서 다시 연결하기

기기가 AP 모드로 돌아왔으므로 [2. 기기 연결하기](02_기기_연결하기.md) **방법 ①** 대로 처음부터 하면 됩니다:
이지롤 앱으로 [기기 등록](../easyroll/02_앱_등록하기.md)(새 WiFi) → ⚙ → **[구역 기기 설정] → [Home Assistant 연결]** 에서 새 HA 브로커 정보 입력.

## HA 전용 기기 — `EZS_HARESET$`

앱에 등록하지 않고 HA만으로 쓰던 기기는 HA에서 명령 한 번으로 초기화합니다. (서버 등록은 그대로 둔 채 기기만 옮길 때도 이 명령을 씁니다.)

!!! note "앱에 등록돼 있던 기기에 직접 보냈다면"

    서버의 기기 등록은 지워지지 않아 **앱에는 '오프라인'으로 남습니다.** (하이브리드 기기는 처음부터 **앱에서 삭제**하는 쪽이 간단합니다.)

    - **같은 집에서 계속 쓸 때**: 기기 WiFi(`EZS...`)에 접속해 공유기 정보만 다시 입력하면 앱으로 복귀 → HA는 **[Home Assistant 연결]** 로 다시 연결
    - **다른 현장으로 옮길 때**: **앱에서 기기 삭제**까지 해 주세요

명령을 보내는 위치(패킷 발행)는 [4. 고급 명령어](04_고급_명령어.md)의 **"명령 보내는 곳"** 과 같습니다.

!!! warning "HA에서는 명령이 `#`가 아니라 `EZS_`로 시작합니다"

    `#HARESET$`가 아니라 **`EZS_HARESET$`** 입니다.

1. HA **설정 → 기기 및 서비스 → MQTT → ⚙ 구성 → 패킷 발행(Publish a packet)** 에서 아래처럼 보냅니다.

| 입력 항목 | 값 |
|---|---|
| 토픽(Topic) | `/<기기ID>` — 예: `/EZS16J1234567` |
| 페이로드(Payload) | `EZS_HARESET$` |

2. 기기가 `/feedback`으로 **`ha_reset:ok`** 응답을 보낸 뒤, 몇 초 후 **자동 재시작**합니다.
3. 재시작하면 HA에서 기기가 **깨끗이 사라지고**, 기기는 **설정용 AP 모드(`EZS...` WiFi)** 로 돌아갑니다.

### 새 장소에서 다시 연결하기

- **하이브리드로 바꾸기 ★권장** — 이지롤 앱으로 [기기 등록](../easyroll/02_앱_등록하기.md) → ⚙ → **[구역 기기 설정] → [Home Assistant 연결]** (방법 ①)
- **계속 HA 전용** — 폰을 기기 WiFi(`EZS...`)에 연결 → 브라우저에 `192.168.4.1` → **[Home Assistant]** → 새 집 WiFi + 새 HA 브로커 정보 입력 → **[저장하고 연결]** (방법 ②-B)

---

!!! success "상·하단(리미트)과 현재 위치는 지워지지 않습니다"

    앱 삭제·`EZS_HARESET$` 모두 **WiFi·HA 연결 정보만** 초기화합니다.
    모터에 저장된 **상/하단 위치는 그대로 유지**되므로, 재설치 후 **리미트를 다시 잡을 필요가 없습니다.**

## 비교 — 어떤 방법을 쓸까요?

| 상황 | 방법 | 연결 상태 | 상/하단 설정 |
|---|---|---|---|
| HA 화면에서 잠깐 숨기기 | `EZS_HADISCOVERY_OFF$` | **유지** (언제든 `EZS_HADISCOVERY$`로 복구) | 유지 |
| HA만 끊고 앱은 계속 (하이브리드) | 앱 **[Home Assistant 연결 해제]** 또는 `EZS_MQTTAWS$` | 앱 전용으로 전환, HA 등록 자동 정리 | 유지 |
| 다른 집/HA로 이전 — 하이브리드 기기 | **앱에서 기기 삭제** | 해제 → AP 모드 복귀, HA 자동 정리 | **유지** |
| 다른 집/HA로 이전 — HA 전용 기기 | `EZS_HARESET$` | 해제 → AP 모드 복귀 | **유지** |
| 완전 공장 초기화 | 기기 버튼 5초 | 해제 → 이지롤 앱 기본 상태 | 유지 |
