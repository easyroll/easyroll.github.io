# 5. 문제해결 (HA)

---

## 연결 단계에서 막힐 때

| 증상 | 확인 |
|---|---|
| WiFi 목록에 EZS...가 안 보임 | 전원 재연결 후 1분 대기. 이미 등록된 기기면 버튼 5초(초기화) 후 재시도 |
| 192.168.4.1이 안 열림 | 폰이 **기기 WiFi(EZS...)** 에 연결됐는지 확인 (집 WiFi 아님). 모바일 데이터 잠시 끄기 |
| 저장했는데 HA에 기기가 안 뜸 | ① 블라인드와 HA가 **같은 공유기**인지 ② 브로커 IP/포트/계정 오타 ③ Mosquitto 애드온 실행 중인지 |
| MQTT 통합 자체가 없음 | HA에서 MQTT 통합 추가 + Mosquitto 애드온 설치 먼저 ([1. 준비물](01_시작하기_준비물.md)) |

## 사용 중 문제

| 증상 | 확인 |
|---|---|
| 카드는 있는데 "사용 불가" 표시 | 기기 전원/WiFi 확인. 기기 LED가 3초 간격 깜빡이면 재연결 중 — 잠시 대기. 하이브리드 기기인데 앱은 정상이면 아래 **앱은 되는데 HA만 안 됨** 참고 |
| 슬라이더가 0/100만 됨 | 기기의 **상/하단 설정** 미완료 — 설정 후 정상 동작 ([2-1. 상/하단 위치 설정](../easyroll/02-1_상하단_위치_설정.md), 앱 없이 쓰는 기기는 [②-B 4단계](02_기기_연결하기.md#4단계--상하단-설정--가장-먼저-하세요)) |
| 엔티티가 사라짐 | `EZS_HADISCOVERY$` 전송으로 재등록 ([4. 고급 명령어](04_고급_명령어.md)) |
| 명령을 보내도 무반응 | 명령이 `EZS_`로 시작하는지, 토픽이 `/<기기ID>`인지 확인 |
| 앱은 되는데 HA만 안 됨 (하이브리드) | HA 브로커(Mosquitto)가 실행 중인지, HA 장비 IP가 바뀌지 않았는지 확인. 기기는 재접속을 계속 시도하므로 브로커가 돌아오면 자동 복구. **IP가 바뀌었다면** 앱에서 ⚙ → [구역 기기 설정] → **[Home Assistant 연결]** 을 새 주소로 다시 실행 (HA 서버는 고정 IP 권장) |
| HA만 안 됨 (HA 전용) — HA 장비 IP가 바뀜 | `http://<블라인드IP>:20318/hasetup` 에서 새 브로커 IP로 **체크 없이** 다시 저장. 블라인드 IP 찾는 법·초기화 경로는 [2. 기기 연결하기 · 알아두기](02_기기_연결하기.md#알아두기) |
| HA는 되는데 앱만 안 됨 (하이브리드) | 인터넷(공유기 WAN) 연결 확인. 인터넷이 복구되면 자동 복구 — 그동안에도 HA로는 제어 가능 |
| 앱에 [Home Assistant 연결] 메뉴가 안 보임 | **기기 소유자 계정**에서만 보입니다 (공유받은 구성원 계정은 불가). 앱이 최신 버전인지도 확인 |
| 기기 정보에 "지원하지 않는 기기" | 펌웨어 V3.2.0 미만 → [7. 기기 업데이트](../easyroll/09_기기_업데이트.md) 후 재시도 |
| 연결 결과 "서버 연결 불가" / "계정 오류" / "응답 없음" | 순서대로: 브로커 주소·포트·브로커 실행 확인 / MQTT 계정·비밀번호 확인 / 기기 전원·WiFi 확인 — **"응답 없음"** 은 펌웨어가 **V3.2.0 미만**일 때도 나옵니다(기기 정보의 Home Assistant 항목이 "미사용"으로 보임). [기기 정보]에서 펌웨어를 확인하고 [7. 기기 업데이트](../easyroll/09_기기_업데이트.md) 후 재시도. **실패한 기기는 설정이 바뀌지 않으니** 고쳐서 바로 재시도 |

## HA(브로커)가 꺼졌을 때 기기는?

NAS 재부팅·HA 업데이트 등으로 브로커가 잠시 사라져도 걱정 없습니다:

- 기기는 **자동으로 계속 재접속**을 시도하고, 브로커가 돌아오면 **스스로 다시 연결**됩니다.
- 그동안에도 **리모컨·버튼은 정상 동작**합니다.
- **HA 전용 기기**는 LED가 **3초에 1번 깜빡**이면 "재연결 시도 중"이라는 표시입니다.
- **하이브리드(앱 + HA) 기기**는 HA가 꺼져도 **LED 변화가 없고** 앱으로 계속 제어됩니다. (하이브리드에서 3초 깜빡임은 인터넷(서버) 재연결 중이라는 뜻입니다)

## 공유기(WiFi)를 바꿨어요

공유기만 바꿨다면 초기화할 필요 없이, **기기가 스스로 설정 모드(AP)로 돌아오길** 기다리면 됩니다.

폰 **WiFi 목록에 `EZS...`로 시작하는 이름**이 다시 뜰 때까지 1~2분 기다립니다. (전원을 뺐다 꽂으면 처음부터 다시 시도하느라 오히려 늦어지니, 그대로 기다려 주세요)

- **하이브리드(앱 + HA)로 쓰는 기기** — 이지롤 앱의 [공유기(WiFi) 변경](../easyroll/08_공유기_변경.md)으로 **새 WiFi만** 잡아 주면 됩니다. 저장된 HA 설정은 그대로라 HA에도 다시 연결됩니다. (공유기를 바꾸면서 **HA 장비의 IP도 바뀌었다면** HA만 조용히 끊기니, 앱에서 **[Home Assistant 연결]** 을 새 주소로 다시 실행하세요 — HA 서버는 고정 IP 권장)
- **HA 전용 기기** — 그 `EZS...` WiFi에 접속 → 브라우저에 **`192.168.4.1`** → **[Home Assistant]** → **새 집 WiFi + HA 브로커 정보** 입력 → **[저장하고 연결]** (입력 항목은 [2. 기기 연결하기](02_기기_연결하기.md) 방법 ②-B 참고)

> 💡 ★상/하단 설정·현재 위치는 어느 경우든 유지되므로 **리미트 재설정은 불필요**합니다.

## HA에서 기기를 삭제했더니 LED가 깜빡여요

**HA 전용 기기**는 HA(Mosquitto)에서 기기 계정을 지우면 접속을 거부당해 **설정 모드(3번 깜빡 LED)** 로 들어갑니다.

- 다시 쓰려면: 계정 복구 후 잠시 기다리면 **자동 복귀**, 또는 [2. 기기 연결하기](02_기기_연결하기.md) 방법 ②-B로 재설정.
- 이지롤 앱으로 돌아가려면: 기기 버튼 5초(초기화) 후 이지롤 앱에서 등록.

**하이브리드(앱 + HA) 기기**는 HA 계정을 지워도 **LED 변화나 설정 모드 진입 없이** HA 쪽 연결만 끊기고, 앱은 그대로 동작합니다.

- 다시 HA로 쓰려면: 계정을 복구하면 자동으로 다시 연결됩니다. 다른 계정을 쓰려면 앱에서 ⚙ → [구역 기기 설정] → **[Home Assistant 연결]** 을 다시 실행하세요. (초기화나 ②-B 재설정은 필요 없습니다 — ②-B로 저장하면 HA 전용으로 바뀝니다.)

> 💡 다른 집·HA로 옮길 때는: 하이브리드 기기는 **앱에서 기기 삭제**만 하면 HA에서도 자동으로 사라집니다. HA 전용 기기는 `EZS_HARESET$` → [기기 이전·삭제하기](06_기기_이전하기.md) *(V3.2.0 이상)*

## 이지롤 앱으로 되돌리고 싶어요

- **하이브리드 기기**: 앱에서 ⚙ → **[구역 기기 설정] → [Home Assistant 연결]** → 기기 선택 → **[Home Assistant 연결 해제]**
- **HA 전용 기기**: 기기 설정 페이지 `http://<블라인드IP>:20318/hasetup` 의 **[Easyroll_Server로 복원]** — 또는 기기 초기화(버튼 5초) 후 앱에서 등록
    - 이 두 방법은 **HA 쪽 기기 등록을 지우지 않습니다.** HA의 **설정 → 기기 및 서비스 → MQTT** 에서 해당 블라인드(EZS...)를 직접 삭제하세요. ([자세히](02_기기_연결하기.md#이지롤-앱으로-되돌리기))
