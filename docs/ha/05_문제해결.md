# 5. 문제해결 (HA)

---

## 연결 단계에서 막힐 때

| 증상 | 확인 |
|---|---|
| WiFi 목록에 EZS...가 안 보임 | 전원 재연결 후 1분 대기. 이미 등록된 기기면 버튼 5초(초기화) 후 재시도 |
| 192.168.4.1이 안 열림 | 폰이 **기기 WiFi(EZS...)** 에 연결됐는지 확인 (집 WiFi 아님). 모바일 데이터 잠시 끄기 |
| 저장했는데 HA에 기기가 안 뜸 | ① 블라인드와 HA가 **같은 공유기**인지 ② 브로커 IP/포트/계정 오타 ③ Mosquitto 애드온 실행 중인지 |
| MQTT 통합 자체가 없음 | HA에서 MQTT 통합 추가 + Mosquitto 애드온 설치 먼저 ([1. 준비물](01_시작하기_준비물.md)) |

## 사용 중 문제

| 증상 | 확인 |
|---|---|
| 카드는 있는데 "사용 불가" 표시 | 기기 전원/WiFi 확인. 기기 LED가 3초 간격 깜빡이면 재연결 중 — 잠시 대기 |
| 슬라이더가 0/100만 됨 | 기기의 **상/하단 설정** 미완료 — 설정 후 정상 동작 |
| 엔티티가 사라짐 | `EZS_HADISCOVERY$` 전송으로 재등록 ([4. 고급 명령어](04_고급_명령어.md)) |
| 명령을 보내도 무반응 | 명령이 `EZS_`로 시작하는지, 토픽이 `/<기기ID>`인지 확인 |
| 앱은 되는데 HA만 안 됨 (하이브리드) | HA 브로커(Mosquitto)가 실행 중인지, HA 장비 IP가 바뀌지 않았는지 확인. 기기는 재접속을 계속 시도하므로 브로커가 돌아오면 자동 복구. IP가 바뀌었다면 `.../20318/hasetup`에서 브로커 IP만 다시 저장(체크 유지) |
| HA는 되는데 앱만 안 됨 (하이브리드) | 인터넷(공유기 WAN) 연결 확인. 인터넷이 복구되면 자동 복구 — 그동안에도 HA로는 제어 가능 |

## HA(브로커)가 꺼졌을 때 기기는?

NAS 재부팅·HA 업데이트 등으로 브로커가 잠시 사라져도 걱정 없습니다:

- 기기는 **자동으로 계속 재접속**을 시도하고, 브로커가 돌아오면 **스스로 다시 연결**됩니다.
- 그동안에도 **리모컨·버튼은 정상 동작**합니다.
- 기기 LED가 **3초에 1번 깜빡**이면 "재연결 시도 중"이라는 표시입니다.

## 공유기(WiFi)를 바꿨어요

공유기만 바꿨다면 초기화할 필요 없이, **기기가 스스로 설정 모드(AP)로 돌아오길** 기다리면 됩니다.

폰 **WiFi 목록에 `EZS...`로 시작하는 이름**이 다시 뜰 때까지 1~2분 기다립니다. (전원을 뺐다 꽂으면 더 빠름)

- **하이브리드(앱 + HA)로 쓰는 기기** — 이지롤 앱의 [공유기(WiFi) 변경](../easyroll/08_공유기_변경.md)으로 **새 WiFi만** 잡아 주면 됩니다. 저장된 HA 설정은 그대로라 HA에도 다시 연결됩니다. (HA 장비 IP가 바뀌었다면 `.../20318/hasetup`에서 브로커 IP만 다시 저장 — 체크 유지)
- **HA 전용 기기** — 그 `EZS...` WiFi에 접속 → 브라우저에 **`192.168.4.1`** → **[Home Assistant]** → **새 집 WiFi + HA 브로커 정보** 입력 → **[저장하고 연결]** (입력 항목은 [2. 기기 연결하기](02_기기_연결하기.md) 방법 ② 참고)

> 💡 ★상/하단 설정·현재 위치는 어느 경우든 유지되므로 **리미트 재설정은 불필요**합니다.

## HA에서 기기를 삭제했더니 LED가 깜빡여요

HA(Mosquitto)에서 기기 계정을 지우면 기기가 접속을 거부당해 **설정 모드(3번 깜빡 LED)** 로 들어갑니다.
- 다시 쓰려면: 계정 복구 후 잠시 기다리면 **자동 복귀**, 또는 [2. 기기 연결하기](02_기기_연결하기.md) 방법 ②로 재설정.
- 이지롤 앱으로 돌아가려면: 기기 버튼 5초(초기화) 후 이지롤 앱에서 등록.
- 다른 집·HA로 옮길 때는: [기기 이전·삭제하기](06_기기_이전하기.md)의 `EZS_HARESET$`를 쓰면 유령 기기 없이 깔끔히 정리됩니다. *(V3.2.0T2 이상)*

## 이지롤 앱으로 되돌리고 싶어요

- HA에 연결된 상태에서 `EZS_MQTTAWS$` 전송 ([4. 고급 명령어](04_고급_명령어.md)) — 또는 기기 초기화 후 앱 등록.
- 하이브리드에서 **HA만 떼고 앱만** 쓰려 할 때도 같은 명령, 또는 `.../20318/hasetup` 페이지의 **[Easyroll_Server로 복원]** 버튼.
