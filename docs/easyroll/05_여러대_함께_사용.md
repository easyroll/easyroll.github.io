# 5. 여러 대 함께 사용

블라인드를 여러 대 설치하면, 똑똑하게 **서로 도우며** 동작합니다. 별도 설정 없이 자동입니다.

---

## 같이 움직이면 높이가 맞춰집니다 (동기화)

여러 대를 동시에 움직이면(전체 채널, 앱 그룹 제어 등):

- **이동 중**: 서로 진행 상황을 주고받으며 **속도를 맞춰** 나란히 움직입니다.
- **멈출 때**: 멈춘 후 서로 높이를 비교해 **같은 높이로 자동 정렬**합니다.

> 💡 창 하나에 블라인드 2~3개를 나란히 단 경우, 줄이 안 맞아 보기 싫은 일이 없도록 자동으로 맞춥니다.

---

## WiFi 신호가 약한 블라인드는 친구가 도와줍니다 (자동 중계)

공유기에서 먼 블라인드가 WiFi 신호가 약하면:

```
[공유기] ←WiFi→ [신호 좋은 블라인드] ←자체 무선→ [신호 약한 블라인드]
                      (다리 역할)              (도움 받는 쪽)
```

- 신호 좋은 블라인드가 **다리(중계기) 역할**을 해서, 약한 블라인드도 앱 명령을 받습니다.
- 신호가 좋아지면 자동으로 직접 연결로 돌아갑니다. **모두 자동 — 설정 불필요.**

> ⚠️ 단, 중계도 거리가 너무 멀면 안 됩니다. 블라인드끼리 너무 떨어져 있으면(다른 층 등) 공유기/증폭기 위치를 조정해 주세요.

---

## 팁

- 여러 대를 자주 같이 쓰면: 리모컨 **전체 채널** 또는 앱의 **그룹 기능**을 활용하세요.
- 일부만 같이 움직이게 하려면: 리모컨 채널을 나눠 등록하세요. ([4. 리모컨](04_리모컨_사용하기.md))
