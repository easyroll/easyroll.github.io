# 2-1. Upper/Lower Limit Setup

**Be sure to complete the Upper/Lower Limit Setup for your blind.**
This is the process of teaching the blind "how far up and how far down it should go." Only after this setup will it **move precisely to the position you want (%)**, and will **saved positions (M1–M3) and alarms** work correctly.

After registration, the guide screen below appears. Tap **[No, I want to set it up!]** to start right away.

![Upper/Lower Limit Setup guide — select purchase type](../images/topbottom_prompt.jpg){ width="300" }

> 💡 The on-screen note "Settings -> Device Management -> Specify top/bottom" is an old path. Today you'll find it under **⚙ next to the zone name → [Zone device settings] → [Top/Bottom limit setting]**.

!!! danger "Please read before you start"

    **In Setting mode, the blind moves without any limit stops.**
    Be sure to press **■ Stop before it reaches the end.** If it keeps winding, the blind can be damaged, so please make sure you understand the steps below before proceeding.

### Setup Steps

1. Before setup, **lower the blind all the way down and then raise it back up.**
2. In **Setting mode**, move the blind to your desired **"topmost"** position → **[Specify top]**
3. Then move it to your desired **"bottommost"** position → **[Specify bottom]**
    - ⚠️ **Always specify the top first, then the bottom!**
4. If you have several blinds, use **◀ ▶** to switch between devices and repeat.

![Specify top and bottom screen — Setting mode, jog steps, motor direction](../images/topbottom.jpg){ width="300" }

!!! tip "Good to know"

    - **To set it up later** — tap the **⚙ next to the zone name → [Zone device settings] → [Top/Bottom limit setting]**
    - **If the direction is reversed** — you can change it with **[Change motor direction]** on the screen.
    - **If you re-set the upper limit** — the lower limit and saved positions are **automatically adjusted along with it**. No need to set everything again.
