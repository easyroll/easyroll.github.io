# DIY Motor Unit Assembly

This is the process of attaching the motor unit to the blind's head rail. All you need is a Phillips screwdriver.

---

## Please Read Before Assembly & Installation

!!! danger "Pre-Installation Checklist"

    - **First roll the blind all the way up**, then begin assembly.
    - By default, viewed from inside the room, the motor is **assembled on the right side** of the blind.
        - **If you install it on the left side**, after assembly you must go to the app's **Upper/Lower Limit Setup page and press the [Motor Direction] button** to change the motor direction. (See [2-1. Upper/Lower Position Setup](02-1_상하단_위치_설정.md).)
    - **Do not remove the cap on the motor unit shown in the photo below.** Assemble it with the cap left in place.
    - Have ready the **QR code card** included with each motor. *(Not applicable to EasyRoll Lite.)*
        - If you are installing two or more blinds, it helps to write each blind's location or number (name) on its card so the QR code cards don't get mixed up!
        - It is the same as the QR code attached to the lower right of the motor unit.

## Assembly Steps

Tap a photo to view it larger.

**1. Loosen the screw on the head rail's side cap.** *(※ The default is right-side assembly — for left-side installation, see the checklist above.)*

![Step 1 — loosen the side cap screw](../images/install/step1.jpg){ width="420" }

**2. Open the side cap and lay the head rail down on the floor.**

![Step 2 — lay down the head rail](../images/install/step2.jpg){ width="420" }

**3. Remove the blind cord.**

![Step 3 — remove the blind cord](../images/install/step3.jpg){ width="420" }

**4. Fit the head rail's side cap into the grooved slot on the side of the motor unit.**

> ※ If there is play because the size doesn't quite fit: **add a 'bushing' first**, then attach the motor unit.

Select the tab that matches your type of head rail:

=== "Box-Type Head Rail"

    ![Box-type joint 1](../images/install/box1.jpg){ width="260" }
    ![Box-type joint 2](../images/install/box2.jpg){ width="260" }
    ![Box-type joint 3](../images/install/box3.jpg){ width="260" }

    !!! warning "Box-Type · Adding a Bushing When There's Play"

        ![Inserting the bushing](../images/install/gapbox1.jpg){ width="300" }
        ![Finished joint](../images/install/gapbox2.jpg){ width="300" }

        **＋ Insert the bushing so it forms a plus (＋) shape.**

=== "Open-Type Head Rail"

    ![Open-type joint 1](../images/install/open1.jpg){ width="260" }
    ![Open-type joint 2](../images/install/open2.jpg){ width="260" }
    ![Open-type joint 3](../images/install/open3.jpg){ width="260" }

    !!! warning "Open-Type · Adding a Bushing When There's Play"

        ![Inserting the bushing](../images/install/gapopen1.jpg){ width="300" }
        ![Side cap insertion point](../images/install/gapopen2.jpg){ width="300" }

        **✕ Insert the bushing at the side cap insertion point so it forms a cross (✕) shape.**

**5. First, check the shape of your blind's pipe.**

![Step 5 — check pipe type A/B](../images/install/step5_v2.jpg){ width="420" }

- Pipe **Type A** → **position A** on the motor unit
- Pipe **Type B** → **position B** on the motor unit

*※ A/B is marked on the motor unit.*

**6. Turn the pipe you identified to match position A/B on the motor unit, then push the motor unit into the pipe.** *(※ Do not remove the motor's cap! Insert it with the cap left in place.)*

![Step 6 — push the motor into the pipe](../images/install/step6_v2.jpg){ width="420" }

**7. Fit the idler into the pipe too, matching its shape (turning it as you go).**

![Step 7 — insert the idler](../images/install/step7.jpg){ width="300" }

**8. Stand the head rail you laid down back into position and close the side cap.**

![Step 8 — stand the head rail up and close the side cap](../images/install/step8.jpg){ width="300" }

**9. Fasten it with the screw. — Motor assembly complete!** *(※ Don't over-tighten the screw! It causes the motor to slow down.)*

![Step 9 — fasten the screw](../images/install/step9_v2.jpg){ width="300" }

!!! info "Install the blind only after you have also checked the power connection below."

    **※ Be sure to plug the adapter (power plug) into the outlet only after all installation is complete.**

## How to Connect the Power

Select the tab that matches the number of blinds you are installing.

=== "Installing 1 Blind"

    **Connection Layout**

    <div class="er-duo" markdown>

    ![Single-blind connection diagram](../images/install/diagram_1unit.jpg)

    ![Single-blind power connection](../images/install/power1.jpg)

    </div>

    1. **Connect the adapter to ①.**
    2. **Route ② up onto the head rail or fix it as far away from the blind fabric as possible.** *(※ Do not remove the protective cap!)*
        - If it touches the fabric, static electricity builds up and causes malfunctions.

=== "Installing 2 or More on a Connected Window"

    **Connection Layout**

    ![Two-blind connection — when the outlet is on the right](../images/install/diagram_2unit.jpg){ width="480" }

    ![Three-blind connection — when the outlet is on the left](../images/install/diagram_3unit.jpg){ width="480" }

    ![Where the power connection cable (③) and adapter (①·②) connect](../images/install/power_multi.jpg){ width="560" }

    1. **Connect the adapter to ①.** *(※ Connect it to the blind nearest the outlet.)*
    2. **Remove the protective cap on ② and connect the power connection cable to ② and ③.** *(※ Do not remove the one protective cap that remains after connecting!)*
    3. **Route the connection points up onto the head rail or fix them as far away from the blind fabric as possible.**
        - If they touch the fabric, static electricity builds up and causes malfunctions.

!!! tip "Outlet Position · Cable Management"

    - **The outlet can be on either the left or the right side.** Just connect the adapter to the motor unit nearest the outlet.
    - The adapter comes in a standard **1.2 m** length, and you can **extend it with a power connection cable**.
    - A **5 m** power connection cable comes in the basic package that contains the adapter, and a **3 m** cable comes with each additional motor.
    - **Manage the cables by routing them up above the head rail or toward the back!**

![Adapter and power connection cable](../images/install/adaptercable_v2.jpg){ width="300" }

![Combi blind bottom-bar screw](../images/install/combi_v2.jpg){ width="300" }

> For a **combi blind**, only **loosen the screw fixed to the bottom bar slightly!** If it is too tight, the tube can't rotate, which causes static electricity and malfunctions.
