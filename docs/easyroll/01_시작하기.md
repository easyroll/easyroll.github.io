# 1. 시작하기

이지롤 스마트 블라인드를 구매해 주셔서 감사합니다. 이 설명서를 따라 하면 누구나 쉽게 설치하고 사용할 수 있습니다.

---

## 구성품

✍️ (구성품 사진 + 목록: 블라인드 본체 / 전원 어댑터 / 리모컨 / 브래킷 / 설명서 등)

## 설치하기

✍️ (브래킷 고정 → 본체 장착 → 전원 연결 순서 사진/그림)

---

## 전원을 켜면

전원을 연결하면 블라인드가 **살짝 내려갔다가 제자리로 돌아옵니다.**
👉 이것은 고장이 아니라 **"정상 작동 중"이라는 인사 동작**입니다. 모터·전원이 정상이라는 뜻이에요.

## 기기 라벨 확인

본체 라벨에 인쇄된 두 가지를 확인해 두세요. 앱 등록 때 필요합니다.

| 라벨 항목 | 예시 | 용도 |
|---|---|---|
| 기기 이름 (ID) | `EZS16A4......` | 앱 등록 시 WiFi 목록에 이 이름이 보임 |
| 비밀번호 (PW) | `u6718....` | 그 WiFi에 접속할 때 입력 |

## 표시등(LED) 한눈에

| LED 모양 | 의미 |
|---|---|
| 꺼져 있음 | 정상 (평소 상태) |
| 천천히 깜빡임 (2초에 1번) | 인터넷은 되는데 서버 연결 중 — 잠시 기다리면 자동 복구 |
| 빠르게 3번 깜빡 + 쉬고 반복 | 설정 모드 (WiFi 재설정/앱 재등록 필요) |
| 리모컨 등록 중 깜빡임 | 리모컨 페어링 진행 중 |

> 💡 LED가 깜빡인다 = 기기가 고장난 게 아니라 **"지금 이런 상태예요"라고 알려주는 것**입니다. 자세한 대처는 [6. 문제해결](06_문제해결_FAQ.md) 참고.
