# 2. 앱 등록하기

스마트폰 앱으로 블라인드를 제어하려면 처음 한 번 등록이 필요합니다. 약 3분 걸립니다.

---

## 준비물

- 스마트폰 (✍️ 앱 이름 + 앱스토어/플레이스토어 링크 또는 QR)
- **집 WiFi 이름과 비밀번호** (2.4GHz 대역이어야 합니다 — 아래 참고)
- 블라인드 라벨의 기기 이름(EZS...)과 비밀번호

> ⚠️ **5GHz 전용 WiFi에는 연결되지 않습니다.** 공유기 이름이 `...5G`로 끝나면 5G가 안 붙은 쪽을 선택하세요. (요즘 공유기는 대부분 2.4GHz를 함께 지원합니다)

---

## 등록 순서

```
① 블라인드 전원 켜기 (살짝 움직였다 돌아오면 준비 완료)
② 앱 실행 → "기기 추가"
③ 폰 WiFi 설정에서 블라인드 이름(EZS...) 선택 → 라벨의 비밀번호 입력
④ 앱으로 돌아와 집 WiFi 이름/비밀번호 입력
⑤ 잠시 기다리면 "등록 완료" → 끝!
```

✍️ (각 단계 앱 스크린샷)

등록이 끝나면 블라인드가 집 WiFi에 연결되고, 이제 **집 밖에서도** 앱으로 제어할 수 있습니다.

---

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| WiFi 목록에 EZS... 가 안 보임 | 전원을 뺐다 다시 꽂고 1분 기다린 후 재시도 |
| 집 WiFi 비밀번호를 잘못 입력함 | 처음(③)부터 다시 — 기기는 자동으로 다시 등록 대기 상태가 됩니다 |
| "등록 실패"가 반복됨 | 공유기가 2.4GHz인지 확인 / 공유기와 블라인드 거리가 너무 멀지 않은지 확인 |
| 이미 등록했던 기기를 다시 등록하고 싶음 | 기기 버튼을 **길게(5초 이상)** 눌러 초기화 → 처음부터 등록 |
