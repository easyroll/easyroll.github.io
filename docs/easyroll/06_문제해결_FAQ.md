# 문제해결 FAQ

문제가 생겼을 때 아래 순서로 확인해 보세요. 대부분 1~2분 안에 해결됩니다.

---

## 가장 먼저 — LED를 보세요

| LED 모양 | 상태 | 해결 |
|---|---|---|
| 꺼져 있음 + 정상 동작 | 정상 | — |
| **3초에 1번 깜빡** | 인터넷은 되는데 서버 연결을 다시 시도 중 | 그대로 두면 **자동 복구**(보통 몇 분 내). 그동안 리모컨·버튼은 정상 |
| **1초 켜짐+1초 꺼짐 반복** | WiFi(공유기)에 연결 못 함 | 공유기 전원/거리 확인 → 공유기를 바꿨다면 [공유기 변경](08_공유기_변경.md) |
| **빠르게 3번 깜빡 + 쉬고 반복** | 서버 등록이 풀림 | 앱으로 재등록 ([2. 기기 등록하기](02_앱_등록하기.md)) — 자동 복구되기도 함 |
| 아예 안 켜지고 무반응 | 전원 문제 | 어댑터/콘센트 확인, 전원 재연결 |

---

## 자주 묻는 질문

### Q. 앱에서 제어가 안 돼요 (리모컨은 되는데)
인터넷/서버 연결 문제입니다. 블라인드가 스스로 복구를 시도하니 **몇 분 기다려 보세요.**
그래도 안 되면: ① 집 인터넷이 되는지 확인 → ② 공유기 재부팅 → ③ 블라인드 전원 재연결.

### Q. WiFi 공유기를 바꿨어요 / 비밀번호를 바꿨어요
[6. 공유기 변경](08_공유기_변경.md)을 보세요. (같은 이름·비밀번호의 새 공유기면 자동 재연결)

### Q. 슬라이더 % 위치가 안 맞아요 / 0과 100만 돼요
**상/하단 설정**이 안 된 상태입니다. [2-1. 상/하단 위치 설정](02-1_상하단_위치_설정.md)을 해주세요.

### Q. 내려가다가 중간에 멈춰요
경로에 걸리는 물건이 있으면 모터 보호를 위해 자동으로 멈춥니다. 걸리는 물건(건조대·화분 등)을 치우고 다시 동작시키세요.

### Q. 전원을 켤 때마다 살짝 움직여요
정상입니다. 전원을 연결하면 모터가 **좌우로 아주 조금씩 회전**하는 확인 동작을 합니다.
👉 이 동작이 보이면 **모터 자체에는 이상이 없다는 뜻**이에요. 그런데도 제어가 안 된다면 모터 고장이 아니라 **WiFi·통신 문제**일 가능성이 큽니다.

### Q. 앱에서 기기를 삭제하고 싶어요
구역 이름 옆 **⚙ → [기기 삭제]** → 지울 블라인드를 선택 → [선택 삭제]. (기기를 다시 쓰려면 [2. 기기 등록하기](02_앱_등록하기.md)로 재등록)

### Q. 처음부터 다시 설정하고 싶어요 (공장 초기화)
기기 본체 버튼을 **5초 이상 길게** 누르세요. 모든 설정(WiFi·등록·리모컨)이 지워지고 새 제품 상태로 돌아갑니다 → [2. 기기 등록하기](02_앱_등록하기.md)부터 다시.
