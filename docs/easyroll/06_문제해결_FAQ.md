# 문제해결 FAQ

문제가 생겼을 때 아래 순서로 확인해 보세요. 대부분 1~2분 안에 해결됩니다.

---

## 가장 먼저 — LED를 보세요

| LED 모양 | 상태 | 해결 |
|---|---|---|
| 꺼져 있음 + 정상 동작 | 정상 | — |
| **3초에 1번 깜빡** | 인터넷은 되는데 서버 연결을 다시 시도 중 | 그대로 두면 **자동 복구**(보통 몇 분 내). 그동안 리모컨·버튼은 정상 |
| **1초 켜짐+1초 꺼짐 반복** | WiFi(공유기)에 연결 못 함 | 공유기 전원/거리 확인 → 공유기를 바꿨다면 [공유기 변경](08_공유기_변경.md) |
| **빠르게 3번 깜빡 + 쉬고 반복** | 서버 등록이 풀림 | 앱으로 재등록 ([2. 기기 등록하기](02_앱_등록하기.md)) — 자동 복구되기도 함 |
| 아예 안 켜지고 무반응 | 전원 문제 | 어댑터/콘센트 확인, 전원 재연결 |

---

## 자주 묻는 질문

### Q. 앱에서 제어가 안 돼요 (리모컨은 되는데)
인터넷/서버 연결 문제입니다. 블라인드가 스스로 복구를 시도하니 **몇 분 기다려 보세요.**
그래도 안 되면: ① 집 인터넷이 되는지 확인 → ② 공유기 재부팅 → ③ 블라인드 전원 재연결.

### Q. WiFi 공유기를 바꿨어요 / 비밀번호를 바꿨어요
[6. 공유기 변경](08_공유기_변경.md)을 보세요. (같은 이름·비밀번호의 새 공유기면 자동 재연결)

### Q. 슬라이더 % 위치가 안 맞아요 / 0과 100만 돼요
**상/하단 설정**이 안 된 상태입니다. [2-1. 상/하단 위치 설정](02-1_상하단_위치_설정.md)을 해주세요.

### Q. 내려가다가 중간에 멈춰요
경로에 걸리는 물건이 있으면 모터 보호를 위해 자동으로 멈춥니다. 걸리는 물건(건조대·화분 등)을 치우고 다시 동작시키세요.

### Q. 전원을 켤 때마다 살짝 움직여요
정상입니다. 전원을 연결하면 모터가 **좌우로 아주 조금씩 회전**하는 확인 동작을 합니다.
👉 이 동작이 보이면 **모터 자체에는 이상이 없다는 뜻**이에요. 그런데도 제어가 안 된다면 모터 고장이 아니라 **WiFi·통신 문제**일 가능성이 큽니다.

### Q. 앱에서 기기를 삭제하고 싶어요
구역 이름 옆 **⚙ → [기기 삭제]** → 지울 블라인드를 선택 → **[선택 삭제]**. (기기를 다시 쓰려면 [2. 기기 등록하기](02_앱_등록하기.md)로 재등록)
삭제하면 기기의 **WiFi 연결 정보도 함께 지워지고 설정 모드로 다시 시작**됩니다(상/하단 위치 설정은 유지). 기기가 꺼져 있을(오프라인) 때 삭제했다면, 다시 쓰기 전에 본체 버튼을 **5초 이상** 눌러 초기화하세요.
Home Assistant에 연결해 쓰던 기기라면, 앱에서 삭제할 때 **Home Assistant 쪽 등록도 자동으로 정리**됩니다. ([기기 이전·삭제하기](../ha/06_기기_이전하기.md))

> 💡 블라인드를 **다른 구역으로 옮기려는 것**이라면 삭제하지 말고 **⚙ → [구역 기기 설정] → [블라인드 구역 변경]** 을 사용하세요. ([2-2. 구역·번호 변경](02-2_구역_번호_정리.md))

### Q. 처음부터 다시 설정하고 싶어요 (공장 초기화)
기기 본체 버튼을 **5초 이상 길게** 누르세요. **WiFi·서버 연결 정보(Home Assistant 설정 포함)** 가 지워지고 등록 대기(설정) 상태로 돌아갑니다. **상/하단 위치와 리모컨 등록은 그대로 유지**됩니다 → [2. 기기 등록하기](02_앱_등록하기.md)부터 다시.

> 💡 **다른 계정으로 옮기려면** 원래 계정의 앱에서 먼저 기기를 삭제하세요. 버튼 초기화만으로는 앱 계정 등록이 풀리지 않아, 다른 계정으로 등록하면 **"○○ 계정에 등록되어 있는 기기입니다. 해당 계정에서 먼저 기기를 삭제해 주세요."** 라는 안내가 나옵니다.

### Q. 기기 IP나 펌웨어 버전은 어디서 보나요?
구역 이름 옆 **⚙ → [구역 기기 설정] → [기기 정보]** 에서 기기 IP·공유기·WiFi 신호·펌웨어 버전·리모컨·Home Assistant 상태를 볼 수 있습니다. ([2-2. 구역·번호 변경](02-2_구역_번호_정리.md#기기-정보-확인))

### Q. Home Assistant와 함께 쓸 수 있나요?
네. 이지롤 앱을 그대로 쓰면서 Home Assistant에 **함께 연결(하이브리드)** 할 수 있습니다. 구역 이름 옆 **⚙ → [구역 기기 설정] → [Home Assistant 연결]** — 자세한 내용은 [Home Assistant 연동 가이드](../ha/index.md)를 보세요. (펌웨어 V3.2.0 이상)
