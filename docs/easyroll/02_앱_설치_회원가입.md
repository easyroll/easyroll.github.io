## 회원가입 · 로그인

앱을 처음 열면 **시작 화면**이 나옵니다. 처음이라면 **[아이디 만들기]**, 이미 가입했다면 화면 아래 "이미 가입을 하셨나요?" 옆 **[로그인]** 을 누르세요. 두 화면 모두 간편 로그인 버튼이 있어요.

| 방법 | 설명 |
|---|---|
| **간편 로그인** | **안드로이드** 구글 · 카카오 · 네이버 / **아이폰** 카카오 · 네이버 · Apple · 구글 — 쓰던 계정으로 바로 시작 (비밀번호 따로 안 만들어도 됨) |
| **이메일 가입** | **[아이디 만들기]** → **[이지롤로 가입하기]** — 이메일 + 비밀번호로 직접 가입 |

![로그인 화면 — 아이디 로그인과 SNS 간편 로그인 (안드로이드 화면, 아이폰은 Apple 버튼 추가)](../images/app_login.jpg){ width="300" }

> 💡 처음 가입 시 **지역(국가)**을 선택합니다. 알람·시간 기능이 그 지역 시간에 맞춰 동작합니다.

로그인했다면 다음 단계 — **블라인드를 앱에 등록**할 차례입니다.
