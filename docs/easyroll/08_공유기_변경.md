# 7. 공유기(WiFi) 변경

공유기를 새것으로 바꿨거나, WiFi 이름·비밀번호가 바뀌면 블라인드가 인터넷에 연결되지 못합니다. 이럴 때 **새 WiFi 정보를 다시 알려주면** 됩니다.

---

## 이럴 때 필요해요

- 인터넷 공유기를 **새 제품으로 교체**했을 때
- WiFi **이름이나 비밀번호를 변경**했을 때
- 이사해서 **다른 공유기**를 쓸 때

> 같은 이름·비밀번호 그대로의 새 공유기라면 **저절로 다시 연결**되니, 이 과정이 필요 없을 수도 있습니다.

---

## 바꾸는 방법

```
① 앱 → 메뉴 → [공유기 변경]
② 안내에 따라 진행 → 새 WiFi 이름·비밀번호 입력
③ 잠시 기다리면 새 공유기로 연결 완료
```

✍️ (공유기 변경 화면 스크린샷 — UserRoute/ChangeWifi, ChangeWifiGuide)

> 💡 새 WiFi도 **2.4GHz**여야 합니다. (`...5G` 말고)

---

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 변경 후에도 연결 안 됨 | 새 WiFi 비밀번호를 다시 확인 → 재시도 |
| 블라인드가 응답 없음 | 블라인드 전원을 뺐다 꽂고 1분 후 재시도 |
| 그래도 안 되면 | 기기를 초기화(본체 버튼 5초 길게)하고 [2. 기기 등록하기](02_앱_등록하기.md)부터 새로 |
