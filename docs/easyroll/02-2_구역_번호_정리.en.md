# 2-2. Change Zone & Number

Use this feature to **change the blind number** you set during registration, or to **move a blind to another zone**.

!!! tip "Nothing to change? Move on to the next step"

    If you'll use it just as registered, go straight to [3. Basic Usage](03_기본_사용법.md).

Tap the **⚙ (gear)** next to the zone name → **[Zone device settings]**, where all the organizing menus are gathered.

![Zone device settings — hub for managing zones, numbers, and devices](../images/zone_hub.jpg){ width="300" }

| Task | How | Example |
|---|---|---|
| **Change blind numbers** | Zone device settings → Change blind numbers | Living Room 1 / Living Room 2 |
| **Move to another zone** | Zone device settings → Move blind to another zone | Living Room → Bedroom |
| **Rename a zone** | Zone device settings → Rename zone | "Zone 1" → "Living Room" |

---

## Checking device info

**[Device info]** in the same **[Zone device settings]** shows the status of each blind. The values you need for customer support or [Home Assistant integration](../ha/index.md) are here.

| Item | Contents |
|---|---|
| **Firmware** | The device software version currently installed ([7. Device Update](09_기기_업데이트.md)) |
| **Network** | Device IP · router ID/IP · Wi-Fi signal strength and channel · MAC |
| **Remote** | Registered remote ID · channel |
| **Home Assistant** | Connected (broker · account) / Not used / Not supported on this device |
