# 3. 기본 사용법

---

## 앱에서 제어하기

✍️ (앱 메인 화면 스크린샷 + 버튼 설명)

| 버튼 | 동작 |
|---|---|
| ▲ 열기 | 맨 위까지 올라감 |
| ▼ 닫기 | 맨 아래까지 내려감 |
| ■ 정지 | 그 자리에 멈춤 |
| 위치 슬라이더 | 원하는 높이(%)로 바로 이동 |

---

## 상단/하단 위치 설정 (처음 설치 후 꼭!)

블라인드가 "어디까지 올라가고 어디까지 내려갈지"를 알려주는 과정입니다.
**이 설정을 해야 % 위치 이동·예약 기능이 정확하게 동작합니다.**

```
① 블라인드를 원하는 "맨 위" 위치로 이동시킨 후 → 앱에서 [상단 설정]
② 블라인드를 원하는 "맨 아래" 위치로 이동시킨 후 → 앱에서 [하단 설정]
```

✍️ (앱 설정 화면 스크린샷)

> 💡 나중에 상단을 다시 설정하면 **하단과 저장된 위치들도 자동으로 같이 보정**됩니다 — 다시 다 잡을 필요 없어요.

---

## 자주 쓰는 위치 저장 (메모리 기능)

자주 쓰는 높이(예: 절반만 열기)를 **최대 4개** 저장해 두고 한 번에 이동할 수 있습니다.

```
저장: 원하는 높이로 이동 → 앱에서 [위치 저장] → 번호(1~4) 선택
이동: 앱에서 저장된 번호를 누르면 그 높이로 바로 이동
```

---

## 예약(알람) 기능

정해진 시간에 자동으로 열리고 닫히게 할 수 있습니다. (예: 아침 7시에 열기)

✍️ (앱 예약 화면 스크린샷)

> 예약 실행에는 인터넷 연결이 필요합니다. (예약 시각에 서버가 블라인드에게 명령을 보내는 방식)

---

## 알아두면 좋은 기능

| 기능 | 설명 |
|---|---|
| **속도 조절** | 앱에서 모터 속도를 단계로 선택 |
| **자식 잠금** | 기기 버튼·리모컨을 잠가 아이의 오조작 방지 (앱 제어는 계속 가능) |
| **장애물 감지** | 내려가다 장애물에 걸리면 자동으로 멈추고 앱에 알림 |
