# 3. 기본 사용법

---

## 앱에서 제어하기

✍️ (앱 메인 화면 스크린샷 — UserRoute/Main, 올림·정지·내림 버튼과 위치 슬라이더 보이게)

| 버튼 | 동작 |
|---|---|
| ▲ 열기 | 맨 위까지 올라감 |
| ▼ 닫기 | 맨 아래까지 내려감 |
| ■ 정지 | 그 자리에 멈춤 |
| 위치 슬라이더 | 원하는 높이(%)로 바로 이동 |

> 💡 **짧게 누르면 조금씩**, **길게 누르면 끝까지**(맨 위/맨 아래) 움직입니다. 짧게 눌렀을 때 움직이는 양은 **이동거리 설정**(아래)에서 바꿀 수 있어요.

---

## 상단/하단 위치 설정 (처음 설치 후 꼭!)

블라인드가 "어디까지 올라가고 어디까지 내려갈지"를 기억하게 하는 과정입니다.
**이 설정을 해야 % 위치 이동·알람이 정확하게 동작합니다.**

```
① 블라인드를 원하는 "맨 위" 위치로 이동 → 앱에서 [상단 지정]
② 블라인드를 원하는 "맨 아래" 위치로 이동 → 앱에서 [하단 지정]
```

✍️ (상/하단 지정 화면 스크린샷 — UserRoute/TopBottom)

> 💡 나중에 상단을 다시 잡으면 **하단과 저장된 위치들도 자동으로 같이 보정**됩니다 — 다시 다 잡을 필요 없어요.

---

## 자주 쓰는 위치 저장 (메모리)

자주 쓰는 높이(예: 절반만 열기)를 **3개(M1·M2·M3)**까지 저장해 두고 한 번에 부를 수 있습니다.

```
저장: 원하는 높이로 이동 → 메모리 버튼(M1~M3)을 길게 누름 → "저장하시겠습니까?" 확인
이동: 메모리 버튼을 짧게 누르면 그 높이로 바로 이동
```

✍️ (메인 화면의 M1~M3 메모리 버튼 스크린샷)

---

## 틸트(각도) 조절 — 콤비/틸트 블라인드

틸트형 블라인드는 **올림/내림 외에 각도(빛 방향)**도 조절됩니다. 메인 화면의 틸트 버튼으로 조절하세요.

✍️ (틸트 조절 화면 스크린샷 — 해당 모델만)

---

## 앱 설정 둘러보기 (메뉴 → 설정)

| 설정 | 무엇 |
|---|---|
| **이동거리 설정** | 짧게 눌렀을 때 움직이는 양. 숫자가 낮을수록 정밀(콤비블라인드 무늬 맞출 때 유용) |
| **구역 이름 변경** | "구역1" → "거실"처럼 알아보기 쉽게 |
| **푸시 알림** | 블라인드 알림을 폰으로 받기 |
| **트리플 쉐이드 모드 / 왼손 모드** | 화면 표시·조작을 취향대로 |
| **지역 변경 · 비밀번호 변경** | 계정 설정 |

✍️ (설정 화면 스크린샷 — UserRoute/Setting)

---

## 알아두면 좋은 점

- **내려가다 무언가에 걸리면 자동으로 멈춥니다** (모터 보호). 걸린 물건을 치우고 다시 동작시키세요.
- **전원을 켤 때마다 살짝 움직이는 것**은 정상(작동 확인 동작)입니다.
