# Troubleshooting FAQ

When something goes wrong, check the items below in order. Most issues are resolved within 1–2 minutes.

---

## First of All — Look at the LED

| LED Pattern | Status | Fix |
|---|---|---|
| Off + working normally | Normal | — |
| **Blinks once every 3 seconds** | Internet is fine, but it is retrying the server connection | Leave it and it will **recover automatically** (usually within a few minutes). Remote and buttons work normally in the meantime |
| **1 second on + 1 second off, repeating** | Cannot connect to WiFi (router) | Check the router's power/distance → if you changed routers, see [Changing Your Router](08_공유기_변경.md) |
| **3 quick blinks + pause, repeating** | Server registration has been lost | Re-register with the app ([2. Registering Your Device](02_앱_등록하기.md)) — it sometimes recovers automatically |
| Won't turn on at all, unresponsive | Power problem | Check the adapter/outlet, reconnect the power |

## Frequently Asked Questions

### Q. The app can't control it (but the remote works)
This is an internet/server connection problem. The blind tries to recover on its own, so **wait a few minutes.**
If it still doesn't work: ① check that your home internet is working → ② restart the router → ③ reconnect the blind's power.

### Q. I changed my WiFi router / I changed the password
See [6. Changing Your Router](08_공유기_변경.md). (If the new router has the same name and password, it reconnects automatically.)

### Q. The slider % position is off / it only goes to 0 and 100
The **Upper/Lower Limit Setup** has not been done. Please complete [2-1. Upper/Lower Position Setup](02-1_상하단_위치_설정.md).

### Q. It stops partway while going down
If there is an object in the way, it stops automatically to protect the motor. Remove whatever is blocking it (a drying rack, a plant pot, etc.) and run it again.

### Q. It moves slightly every time I turn the power on
This is normal. When you connect the power, the motor performs a check by **rotating a tiny bit left and right**.
👉 If you see this movement, it means **the motor itself is fine**. If control still doesn't work, it is most likely a **WiFi/communication problem** rather than a motor failure.

### Q. I want to delete a device from the app
Tap the **⚙ next to the zone name → [Delete Device]** → select the blind to remove → [Delete Selected]. (To use the device again, re-register it via [2. Registering Your Device](02_앱_등록하기.md).)

### Q. I want to start over from scratch (factory reset)
Press and hold the button on the device body for **5 seconds or more**. All settings (WiFi, registration, remote) are erased and it returns to a new-product state → start again from [2. Registering Your Device](02_앱_등록하기.md).
