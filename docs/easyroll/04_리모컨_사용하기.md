# 5. 리모컨 사용하기

리모컨은 **WiFi 없이도** 동작합니다(전용 무선 신호). 인터넷이 끊겨도 리모컨은 항상 됩니다.

![이지롤 전용 리모컨](../images/remote.jpg){ width="180" }

---

## 리모컨 등록 (채널 등록)

리모컨을 쓰려면 **블라인드를 리모컨 채널에 등록**해야 합니다. 등록 방법은 두 가지입니다.

=== "앱으로 등록 (권장)"

    앱 화면에서 채널을 눌러 지정하는 방식이라 가장 쉽습니다.

    !!! warning "먼저 기기가 앱에 등록되어 있어야 합니다"

        블라인드가 **앱에 등록된 상태**여야 앱으로 리모컨을 등록할 수 있습니다. 아직 등록 전이라면 [2. 기기 등록하기](02_앱_등록하기.md)를 먼저 진행해 주세요.
        앱에 등록하지 않고 사용하실 경우에는 **[리모컨으로 직접 등록]** 탭을 참고하세요.

    위치: 구역 이름 옆 **⚙** → **[구역 기기 설정]** → **[리모컨 채널 등록/수정]**

    1. **[리모컨 채널 등록/수정]** 을 엽니다.
    2. 블라인드마다 사용할 **채널(1~5)을 선택**합니다.
    3. **저장**하면 등록 완료입니다.

    ![앱에서 리모컨 등록 — 블라인드별 채널 지정](../images/remote_register.jpg){ width="300" }

    ![등록된 리모컨의 채널 변경](../images/remote_channel.jpg){ width="300" }

    > 💡 나중에 채널을 바꾸고 싶을 때도 같은 메뉴에서 수정하면 됩니다.

=== "리모컨으로 직접 등록 (앱 없이)"

    앱 없이 **리모컨과 블라인드 본체만으로** 등록하는 방법입니다.

    #### 1번 채널에 블라인드 1개 등록하기

    ![① 좌측 버튼 길게 · ② 정지 버튼 5초 이상](../images/remote/ch_step12.jpg){ width="520" }

    1. 리모컨의 **[◀ 좌측] 버튼을 길게**(1초 이상) 누릅니다.
    2. **[■ 정지] 버튼을 5초 이상 길게** 누릅니다.
        - 모든 블라인드 모터의 **LED가 깜빡입니다.**
    3. **1번 채널로 지정할 블라인드 모터의 리셋버튼**을 **짧게 힘껏** 눌러 주세요.
        - LED가 빠른 속도로 여러 번 깜빡이면 **1번 채널 지정 완료!**

    ![블라인드 모터의 리셋버튼 위치](../images/remote/ch_reset.jpg){ width="360" }

    #### 2~5번 채널 등록하기

    1번 과정에서 **[▶ 우측] 버튼을 짧게 누르는 횟수**만 달라지고, 나머지는 모두 같습니다.

    | 채널 | ① 단계에서 |
    |---|---|
    | **1번** | [◀ 좌측] 길게만 |
    | **2번** | [◀ 좌측] 길게 + [▶ 우측] 짧게 **한 번** |
    | **3번** | [◀ 좌측] 길게 + [▶ 우측] 짧게 **두 번** |
    | **4번** | [◀ 좌측] 길게 + [▶ 우측] 짧게 **세 번** |
    | **5번** | [◀ 좌측] 길게 + [▶ 우측] 짧게 **네 번** |

    ![좌측 길게 + 우측 짧게 — 채널 선택](../images/remote/ch_multi_press.jpg){ width="360" }

    #### 여러 대를 한 채널에 묶기 (그룹 등록)

    한 채널에 블라인드를 **여러 개** 등록하면 그 채널에서 함께 움직입니다.
    방법은 같고, ③ 단계에서 **묶을 블라인드 모두의 리셋버튼**을 차례로 눌러 주면 됩니다.

    ![여러 대의 리셋버튼을 차례로 누르기](../images/remote/ch_group_reset.jpg){ width="400" }

    > 💡 등록은 전원이 꺼져도 유지됩니다.

## 리모컨 버튼 알아보기

![리모컨 버튼 안내](../images/remote/remote_buttons.jpg)

| 버튼 | 동작 |
|---|---|
| **⌃ 올림** | 짧게 = 일정 거리만큼 올라감 · 길게 = 끝까지 올라감 |
| **■ 정지** | 움직이는 블라인드가 정지 |
| **⌄ 내림** | 짧게 = 일정 거리만큼 내려감 · 길게 = 끝까지 내려감 |
| **◀ ▶ 채널 선택** | 짧게 누를 때마다 `1 → 2 → 3 → 4 → 5 → ALL` 순으로 이동<br>**[▶ 우측] 길게** = 전체 블라인드 선택 · **[◀ 좌측] 길게** = 1번 블라인드 선택 |
| **M 선호높이(메모리)** | **길게** = 현재 위치를 저장 · **짧게** = 저장한 위치로 이동 |
| **램프** | 버튼을 누를 때마다 점등 (짧게 누르면 1번, 길게 누르면 2번) |

> 💡 채널을 선택하면 **선택된 블라인드가 위아래로 살짝 움직여** 알려줍니다.

## 채널로 여러 대 제어

| 채널 | 동작 |
|---|---|
| **1 ~ 5** | 그 채널에 등록된 블라인드만 동작 |
| **ALL** | 등록된 모든 블라인드가 함께 동작 |

> 예: 거실 블라인드 3대를 채널 1·2·3에 각각 등록 → 채널을 바꿔가며 하나씩 제어.
> 여러 대를 **같은 채널**에 등록하면 그 채널에서 함께 움직입니다.

---

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 눌러도 반응 없음 | 채널이 맞는지 확인 → 배터리 교체 → 재등록 |
| 한 번 눌렀는데 옆 블라인드도 움직임 | 채널이 겹치게 등록됨 — 각각 다른 채널로 재등록 |
| 등록이 안 됨 | 본체 가까이(1~2m)에서 재시도 |
