# 4. 리모컨 사용하기

리모컨은 WiFi 없이도 동작합니다 (전용 무선 신호 사용). 인터넷이 끊겨도 리모컨은 항상 됩니다.

---

## 리모컨 등록 (페어링)

새 리모컨이나 추가 리모컨은 처음 한 번 등록이 필요합니다.

```
① 블라인드 본체의 버튼을 짧게 1번 누름   → LED가 깜빡이기 시작 (등록 대기)
② 리모컨의 설정 버튼을 길게 누름          → 리모컨이 등록 신호를 보냄
③ 본체 버튼을 다시 1번 누름              → LED 확인 깜빡임 → 등록 완료!
```

✍️ (리모컨 사진 + 설정 버튼 위치 표시)

- 등록은 전원이 꺼져도 유지됩니다.
- 리모컨 1개로 **채널을 나눠 여러 대**를 제어할 수 있습니다 (아래 참고).

---

## 채널 사용 (여러 대 제어)

리모컨의 채널 선택으로 블라인드를 골라 제어합니다.

| 채널 | 동작 |
|---|---|
| 1 ~ 4 | 각 채널에 등록된 블라인드만 동작 |
| **전체(5)** | 등록된 모든 블라인드가 함께 동작 |

> 등록(페어링)할 때 리모컨이 맞춰져 있던 채널이 그 블라인드의 채널이 됩니다.
> 예: 거실 블라인드 3대를 채널 1·2·3에 각각 등록 → 개별 제어 + 전체 채널로 한꺼번에.

---

## 버튼 동작

| 리모컨 버튼 | 동작 |
|---|---|
| ▲ | 맨 위까지 올라감 (이동 중 누르면 정지) |
| ▼ | 맨 아래까지 내려감 |
| ■ (정지) | 멈춤 |
| ✍️ (기타 버튼) | (미세 이동/메모리 버튼 등 실제 리모컨 사양대로 채우기) |

---

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 리모컨을 눌러도 반응 없음 | 채널이 맞는지 확인 → 배터리 확인 → 재등록 |
| 한 번 눌렀는데 옆 블라인드도 움직임 | 채널이 겹치게 등록됨 — 각각 다른 채널로 재등록 |
| 등록이 안 됨 | 본체 가까이(1~2m)에서 재시도. 자식잠금이 켜져 있으면 해제 후 |
