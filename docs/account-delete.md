# 계정 및 데이터 삭제

**이지롤 스마트 블라인드** 앱(개발: 이노쉐이드 Inoshade Co., Ltd.)의 계정과 관련 데이터를 삭제하는 방법입니다.

## 앱에서 직접 삭제하기

1. 이지롤 앱에 로그인합니다.
2. 메인 화면 오른쪽 위 **≡ (설정)** 을 누릅니다.
3. **회원 정보 변경**을 누릅니다.
4. 화면 아래 **계정 삭제** 를 누르고 확인합니다.

삭제는 **즉시** 처리되며 되돌릴 수 없습니다. 같은 이메일로 다시 가입하면 새 계정으로 시작합니다.

## 앱을 사용할 수 없을 때

앱을 삭제했거나 로그인할 수 없다면, 가입한 이메일 주소로 아래 연락처에 **계정 삭제**를 요청해 주세요. 본인 확인 후 처리하고 결과를 알려 드립니다.

- 전화: +82-31-358-1016

## 삭제되는 데이터

계정을 삭제하면 다음 정보가 **즉시** 삭제됩니다.

- 계정 정보(이메일 주소, 사용자 ID, 로그인 정보, 소셜 로그인 연결)
- 등록한 블라인드 기기와 구역 정보
- 예약(알람)
- 가족·동료·임시 관리자 공유 연결
- 앱 알림용 기기 토큰

## 보관 기간

- **서버 운영 로그**와 **데이터 백업**에는 삭제 전 기록이 남아 있을 수 있으며, **최대 30일** 이내에 순차적으로 자동 삭제됩니다.
- 앱 사용 통계·오류 기록(Firebase)은 개인을 식별하지 않는 형태로 Google 정책에 따라 보관됩니다.
- 블라인드 기기 자체에 저장된 설정(공유기 정보 등)은 기기를 초기화하면 지워집니다. 계정 삭제 전에 앱에서 **기기 삭제**를 하면 기기도 함께 초기화됩니다.
