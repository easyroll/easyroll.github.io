    구성원 추가 (가족·동료와 함께 쓰기)

    초대 코드 하나로 가족이나 동료를 초대해, 내 블라인드를 함께 제어할 수 있습니다. 구역 전체를 통째로, 또는 블라인드 하나씩 골라서 권한을 줄 수 있어요.

    먼저 알아두기

    • 초대한 사람(주인) 이 허용한 구역·블라인드만 구성원에게 보이고 제어됩니다.
    • 구성원도 예약(알람) 을 만들 수 있어요. (목록에 "○○님의 예약"으로 표시)
    • 최대 5명까지 초대할 수 있습니다.
    • 초대 코드는 6자리이고, 10분 동안 1회만 사용할 수 있어요.

    ① 구성원 초대하기 (블라인드 주인)

    1. 앱 메뉴 ≡ → [설정] → [구성원 관리]
    2. [+ 초대하기]
    3. 초대 유형 선택 — 가족 또는 동료
    4. 허용할 구역 선택
      • [구역 전체] 를 켜면 그 구역의 모든 블라인드(앞으로 추가될 블라인드까지) 공유
      • 화살표(⌄)를 눌러 블라인드를 하나씩 골라 공유할 수도 있어요 (N/M대 선택)
    5. [초대 코드 만들기] → 6자리 코드와 QR 이 나옵니다
    6. [문자 또는 카톡으로 코드 보내기] 로 상대에게 전달

    💡 코드는 10분간 1회만 유효해요. 시간이 지났으면 [새 코드 만들기] 를 누르세요.

    ② 초대 받기 (초대받은 사람)

    1. EasyRoll 앱에 로그인 (앱이 없으면 먼저 설치·회원가입)
    2. 앱 메뉴 ≡ → [설정] → [구성원 관리] → [초대 코드 입력]
    3. 받은 6자리 코드를 입력하거나 [QR 코드 스캔] → [연결하기]
    4. 연결되면, 공유받은 구역이 메인 화면에 "공유 · ○○님" 표시로 나타납니다.

    ⚠️ 코드가 안 될 때 — 코드가 만료(10분 경과) 됐거나, 잘못 입력했거나, 내가 만든 코드는 사용할 수 없어요. 여러 번 실패하면 잠시 후 다시 시도해 주세요.

    함께 쓸 때

    구분 할 수 있는 것
    구성원 허용된 구역·블라인드 제어 · 예약(알람) 만들기
    주인 언제든 권한 회수 · 구성원 삭제

    💡 구성원이 만든 예약은 목록에 "○○님의 예약" 으로 표시됩니다. ⚠️ 권한을 회수·해제·삭제하면, 그 구성원이 그 블라인드·구역에 만든 예약도 함께 삭제됩니다.

    관리하기 (블라인드 주인)

    [설정] → [구성원 관리] 에서:

    하고 싶은 것 방법
    구역 하나 허용 끄기 구성원의 [허용 구역] 에서 해당 구역 허용 해제
    블라인드 하나만 회수 공유한 블라인드에서 회수
    구성원 내보내기 구성원 선택 → [구성원 삭제]

    ⚠️ 위 어느 경우든, 해당 구성원이 만든 관련 예약도 함께 삭제됩니다.

    공유 그만두기 (초대받은 사람)

    [설정] → [구성원 관리] → 공유받은 블라인드 에서 [공유 나가기] 를 누르세요.

    나가면 그 구역을 더는 제어할 수 없고, 내가 만든 해당 구역 예약도 삭제됩니다.
