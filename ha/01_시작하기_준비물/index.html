    1. 시작하기 — Home Assistant 연동 준비물

    이지롤 스마트 블라인드는 Home Assistant(HA) 에 직접 연결할 수 있습니다. 연결하면 HA 대시보드에서 블라인드를 제어하고, HA 자동화(일출/일몰, 온도 연동 등)에 활용할 수 있습니다.

    어떤 방식인가요?

    [Home Assistant] ←── 집 안 네트워크(MQTT) ──→ [블라인드]

    • 클라우드를 거치지 않는 로컬 연결입니다 — 인터넷이 끊겨도 집 안에서 동작.
    • HA의 MQTT 통합을 사용하며, 블라인드가 자동으로 등록됩니다(별도 코드 작성 불필요).

    준비물 체크리스트

    항목 설명
    Home Assistant 설치되어 동작 중 (HA OS, 컨테이너 등 무관)
    MQTT 브로커 HA 애드온 Mosquitto broker 권장 — 설치 방법은 아래 참고
    MQTT 사용자 계정 HA 사용자 1개 (예: easyroll1) — 블라인드가 이 계정으로 접속
    같은 네트워크 블라인드와 HA가 같은 공유기에 연결되어 있어야 함
    블라인드 펌웨어 v2.9.7 이상 (웹 설정 방식 지원)

    Mosquitto broker 설치하기

    MQTT 브로커가 아직 없다면 HA 애드온으로 설치합니다. (이미 쓰고 계시면 건너뛰세요)

    ① 애드온 설치

    1. HA 좌측 메뉴 설정 → 앱(버전에 따라 애드온) 으로 들어갑니다.
    2. 우측 아래 [애드온 스토어] 를 엽니다.
    3. 검색창에 mosquitto 를 입력해 Mosquitto broker 를 찾습니다.
    4. [설치] 를 누릅니다. (1~2분 소요)

    ② 실행 설정

    설치가 끝나면 애드온의 [정보] 탭 오른쪽 Controls 영역에서 설정합니다.

    1. [시작] 을 눌러 실행합니다. (이미 실행 중이면 중지 / 재시작 버튼이 보입니다)
    2. 아래 두 가지를 켜 두면 안정적입니다.
      • 부팅시 자동 시작 — HA가 켜질 때 브로커도 자동으로 실행
      • 실행 감시 — 브로커가 멈추면 자동으로 다시 시작
    3. 왼쪽 위 상태가 Running(실행 중) 으로 표시되면 정상입니다.

    💡 같은 화면 오른쪽 아래의 호스트 이름 core-mosquitto 는 뒤에서 MQTT 통합을 수동으로 추가할 때 브로커 주소로 사용합니다. 💡 자동 업데이트는 꺼 두어도 됩니다. (원하실 때 수동으로 업데이트)

    ③ 포트 확인 (기본값 그대로 두면 됩니다)

    애드온 상단의 [구성] 탭 → 맨 아래 네트워크 항목에 포트가 이미 구성되어 있습니다.

    포트 용도
    1883 Normal MQTT — 블라인드가 사용하는 포트
    1884 MQTT over WebSocket
    8883 Normal MQTT with SSL
    8884 MQTT over WebSocket with SSL

    💡 블라인드는 1883 만 사용합니다. 특별한 이유가 없다면 기본값 그대로 두세요.

    그 밖의 설정은 건드리지 마세요

    같은 [구성] 탭에 있는 SSL·인증서(Certificate/Private Key)·Log Types·Customize 등은 이지롤 연동에 필요하지 않습니다. 기본값 그대로 두세요.

    특히 Require Client Certificate를 켜면 블라인드가 브로커에 접속하지 못합니다.

    ④ 블라인드가 사용할 MQTT 계정 만들기

    Mosquitto는 HA 사용자 계정으로 로그인합니다. 블라인드 전용 계정을 하나 만들어 주세요.

    1. 설정 → 구성원(버전에 따라 사람·사용자) → [사용자 추가]
    2. 이름·아이디를 정합니다. (예: easyroll1)
    3. 비밀번호를 정해 메모해 둡니다. — 블라인드 설정에 입력할 값입니다.
    4. 관리자 권한은 필요 없습니다.

    ⑤ MQTT 통합 확인

    블라인드가 HA와 대화하려면 MQTT 통합구성요소가 등록되어 있어야 합니다.

    설정 → 기기 및 서비스 → 상단 [통합구성요소] 탭으로 들어가서, 아래 세 경우 중 내 화면에 맞는 것을 따라 하세요.

    경우 1 — 아래쪽 "구성된 통합구성요소" 목록에 MQTT 카드가 이미 있다

    이미 등록된 상태입니다. 아무것도 하지 않아도 됩니다. (2. 기기 연결하기로 진행)

    경우 2 — 위쪽 "발견된 통합구성요소"에 MQTT가 보인다

    카드의 [추가] 버튼을 누르고, 이어지는 창에서 [제출] 하면 등록됩니다.

    경우 3 — 어디에도 MQTT가 없다 (직접 추가)

    1. 화면 우측 아래 [＋ 통합구성요소 추가] 를 누릅니다.
    2. 검색창에 MQTT 를 입력해 선택합니다.

    3. 아래 값을 입력하고 [제출] 합니다.

      입력 항목 값
      브로커 core-mosquitto
      포트 1883
      사용자 이름 / 비밀번호 ④에서 만든 MQTT 계정

    💡 등록이 끝나면 "구성된 통합구성요소" 목록에 MQTT 카드가 나타납니다.

    💡 여기까지 하면 블라인드를 연결할 준비가 끝납니다. 이어서 2. 기기 연결하기로 진행하세요.

    미리 확인해 둘 정보 3가지

    연결 단계에서 입력해야 하니 메모해 두세요:

    1. 브로커 IP = HA가 설치된 장비의 IP (예: 192.168.0.14)
    2. HA 화면: 설정 → 시스템 → 네트워크에서 확인
    3. 브로커 포트 = 기본 1883
    4. MQTT 사용자 / 비밀번호 = 위에서 만든 계정

    ⚠️ HA를 NAS 가상머신 등에 설치한 경우, IP는 공유기에서 보이는 LAN IP여야 합니다 (172.30.x.x 같은 내부 주소 아님).
