    Moving / Removing a Device

    How to move a device that was connected to HA to another home, router or HA, or remove it cleanly from HA. The procedure depends on the connection mode — a Hybrid (app + HA) device only needs to be deleted in the app, while an HA-only device is reset with a single command.

    Firmware required — V3.2.0 or later

    The procedures below (automatic HA cleanup on app deletion, EZS_HARESET$) work on firmware V3.2.0 or later. Check the version in the app under [Zone device settings] → [Device info] → Firmware, or with the EZS_VER$ command (HA-only devices). If it's lower, update first via 7. Device Update.

    Hybrid (app + HA) device — just delete it in the app

    1. In the EasyRoll app, tap ⚙ next to the zone name → [Delete device] → select the blinds to remove (select all of them to clear the zone) → [Delete selected] → [Confirm] (the screenshot shows the Korean app)
    2. The device receives the deletion notice, cleans up its HA registration by itself, clears its Wi-Fi/HA settings and restarts → it returns to setup AP mode (EZS... Wi-Fi).
    3. The device disappears from HA within seconds (no ghost "unavailable" device is left behind).

    💡 If the device was powered off at the moment of deletion, it cleans itself up within 3–4 minutes after it is next powered on.

    💡 If you only want to disconnect HA and keep using the app, use Disconnect from Home Assistant instead of deleting.

    Reconnecting at the new location

    Since the device is back in AP mode, simply start over with Method ① in 2. Connecting the Device: register the device with the EasyRoll app (new Wi-Fi) → ⚙ → [Zone device settings] → [Home Assistant] and enter the new HA broker info.

    HA-only device — EZS_HARESET$

    A device used with HA only (never registered in the app) is reset with a single command from HA. (Use the same command when you want to move a device while keeping its server registration.)

    If you sent it to a device that was registered in the app

    The server-side registration is not removed, so the device stays in the app as 'offline'. (For a Hybrid device, simply deleting it in the app is the easier route.) On a Hybrid device, the ha_reset:ok reply in step 2 below goes to the EasyRoll server and doesn't appear in HA, but you can still see the device disappear from HA and restart.

    • To keep using it in the same home: connect to the device Wi-Fi (EZS...) and re-enter just the router info to bring it back to the app → reconnect HA with ⚙ → [Zone device settings] → [Home Assistant] in the app
    • To move it to another site: also delete the device in the app

    Send the command from the same place as in 4. Advanced Commands — "Where to send commands".

    In HA, commands start with EZS_, not #

    It's EZS_HARESET$, not #HARESET$.

    1. In HA, go to Settings → Devices & Services → MQTT → ⚙ Configure → Publish a packet and send:

      Field Value
      Topic /<device ID> — e.g. /EZS16J1234567
      Payload EZS_HARESET$

    2. The device replies with ha_reset:ok on /feedback, then restarts automatically a few seconds later.

    3. After restarting, the device disappears cleanly from HA and returns to setup AP mode (EZS... Wi-Fi).

    Reconnecting at the new location

    • Switch to Hybrid ★Recommended — register the device with the EasyRoll app → ⚙ → [Zone device settings] → [Home Assistant] (Method ①)
    • Stay HA only — connect your phone to the device Wi-Fi (EZS...) → open 192.168.4.1 in a browser → [Home Assistant] → enter the new home Wi-Fi + new HA broker info → [저장하고 연결] (Save and Connect) (Method ②-B)

    Upper/lower limits and the current position are NOT erased

    Both app deletion and EZS_HARESET$ clear only the Wi-Fi/HA connection info. The upper/lower positions stored in the motor are kept, so you don't need to set the limits again after reinstalling.

    Comparison — which method should I use?

    Situation Method Connection Limit settings
    Temporarily hide from the HA screen EZS_HADISCOVERY_OFF$ Kept (restore anytime with EZS_HADISCOVERY$) Kept
    Drop HA but keep the app (Hybrid) App [Disconnect from Home Assistant] Switches to app only; HA registration cleaned up automatically Kept
    Move to another home/HA — Hybrid device Delete the device in the app Cleared → back to AP mode; HA cleaned up automatically Kept
    Move to another home/HA — HA-only device EZS_HARESET$ Cleared → back to AP mode Kept
    Full factory reset Hold device button 5s Cleared → default (EasyRoll app) state Kept
